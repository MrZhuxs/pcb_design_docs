电气特性可以查手册，但**手上这一颗到底是什么、哪一端是正、能不能手焊**——这些必须当场认出来。这一页收的就是这类「不看手册也该知道」的实物知识。

<Callout type="info" title="这一页怎么用">
- **拿着元件来对**：第一节查丝印，第二节认极性，第四节挑封装，第五节认连接器间距。
- **买料前看第四、五节**：封装决定了价格、贴片费、能不能手焊，选错了要重新打样。
- **拆板时看第一、二节**：贴片件的本体上几乎没有字，能看出容值的只有封装配色和 BOM。
- 位号与符号在 [附录 A](/docs/appendix/symbols)，引脚名与缩写见 [附录 B](/docs/appendix/pins)。
</Callout>

## 一、丝印怎么读

### 1.1 电阻：三位数、四位数、字母当小数点

| 丝印 | 阻值 | 规则 |
| --- | --- | --- |
| `103` | 10 kΩ | 前两位是有效数字，第三位是 10 的次方：10 × 10³ |
| `472` | 4.7 kΩ | 47 × 10² |
| `000` / `0R` | 0 Ω | 跳线，兼作单点接地或保险丝用 |
| `4R7` | 4.7 Ω | `R` 就是小数点 |
| `R10` | 0.10 Ω | 小于 1 Ω 时这么写，电流检测电阻常见 |
| `1002` | 10 kΩ | 四位数 = 1% 精密电阻：100 × 10² |
| `4700` | 470 Ω | 470 × 10⁰ |

<Callout type="warn" title="000 与 0R 不是「没装」">
`0R` 是真实存在的 0 Ω 电阻，用来跨接、跳线、单点接地。BOM 里**不装**的位号会写 `DNP`、`NI` 或 `NC`——两者在图上长得像，含义完全不同。
</Callout>

### 1.2 电容：104 到底是多少

| 丝印 | 容量 | 说明 |
| --- | --- | --- |
| `104` | 100 nF（0.1 µF） | 10 × 10⁴ **pF** —— 单位永远是 pF |
| `103` | 10 nF | 10 × 10³ pF |
| `223` | 22 nF | 22 × 10³ pF |
| `474` | 470 nF | 47 × 10⁴ pF |
| `47p` / `47` | 47 pF | 小于 100 pF 直接写数值 |
| `470 16V` | 470 µF / 16 V | 电解电容直接标容量与耐压 |

<Pitfall>`104` 不是 104 pF，是 100 nF。这个误读差 1000 倍，是新手最常见的量级事故；写 BOM 时也容易把「104」直接抄成「104pF」。</Pitfall>

<Callout type="info" title="贴片 MLCC 的本体基本没有字">
0402/0603 的陶瓷电容本体几乎不印任何标记（空间不够），0805 以上偶尔有一个色点。所以**拆板时看不出贴片电容的容值**——只能靠位置推断（去耦基本都是 100 nF）或者量。这也解释了为什么原理图上的位号与参数必须写全。
</Callout>

### 1.3 电感、保险丝、晶振

| 丝印 | 含义 | 说明 |
| --- | --- | --- |
| `4R7` | 4.7 µH | 与电阻同一套规则，`R` 是小数点 |
| `100` | 10 µH | 10 × 10⁰ µH |
| `220` | 22 µH | 功率电感常直接印型号或代号 |
| 一体成型电感 | 只印厂标 + 批次 | 电感量、饱和电流必须查型号 |
| 贴片保险丝 | 通常无标记 | 只能靠 BOM 与封装区分 |
| 晶振 | `25.000` / `16M` | 直接印频率，无极性 |

### 1.4 IC 丝印：三段字，只有第一段是型号

| 段 | 内容 | 用途 |
| --- | --- | --- |
| 第一行 | 型号缩写或完整型号 | 唯一能用来查资料的信息 |
| 第二行 | 批次码 / 晶圆代号 | 追溯生产批，选料时无关 |
| 第三行 | 日期码（`YYWW` 或 `WWYY`） | 判断库存年份，影响焊接与可靠性 |

<Pitfall>小封装上的「型号」经常是**代号**而不是完整型号：SOT-23 上的 `662K` 是 XC6206P332MR，`SGM2019-3.3` 会缩成 `S19`。照抄丝印进 BOM 会买不到料——正确做法是按封装 + 引脚数 + 应用场景反查。</Pitfall>

三种常见反查方式：厂家手册末尾的 Marking Information 表、商城按「封装 + 丝印」筛选、拍照识别的丝印反查工具。反查结果要用引脚定义再核对一遍。

## 二、极性怎么认

  <MarkingCard id="DIODE" code="▮" name="二极管" hint="色带端 = 阴极 K" />
  <MarkingCard id="LED" code="◣" name="贴片 LED" hint="缺角/绿点那一端 = 阴极" />
  <MarkingCard id="IC" code="①" name="集成电路" hint="圆点、缺口、斜切角都指 pin1" />
</MarkingAtlas>

| 器件 | 极性标记 | 哪一端是正 / 阴极 | 接反的后果 |
| --- | --- | --- | --- |
| 铝电解电容 | 侧面色带 + 引脚长短 | 色带端是**负极** | 鼓包、漏液，甚至炸开 |
| 钽电容 | 一条粗横杠 | 横杠端是**正极** | 短路失效，可能起火 |
| 二极管 | 本体色带 | 色带端是**阴极 K** | 反向击穿、整路短路 |
| 稳压二极管 | 色带（同二极管） | 色带端是**阴极**，正常反向工作 | 接反就成正向导通，稳压失效 |
| LED | 缺角 / 绿点 / 短脚 / 封装内大焊盘 | 缺角与短脚端是**阴极** | 不亮；大焊盘是散热用，别当正极 |
| 集成电路 | 圆点、缺口、斜切角 | 那个角是 **pin1** | 整颗芯片装反，可能全烧 |
| 连接器 | 外壳上的 `▲`、丝印的 `1` | `1` 脚 | 排线反插，可能短路电源 |
| 晶振 / 电阻 / 陶瓷电容 | 无极性 | — | 反过来也能焊，不影响 |

<Callout type="success" title="一条通用验证法">
有极性的器件，**焊盘几乎总是不对称的**（一端的焊盘更大或更靠内），丝印框上也常有一条短线指向 pin1 或正极。拿不准时先看焊盘形状，比看丝印清楚。
</Callout>

## 三、数值与系列

### 3.1 为什么是 47 而不是 50

| 系列 | 允许的数值（×10ⁿ） | 精度 | 用在哪 |
| --- | --- | --- | --- |
| E6 | 10、15、22、33、47、68 | ±20% | 电解电容、老器件 |
| E12 | 10、12、15、18、22、27、33、39、47、56、68、82 | ±10% | 通用阻容 |
| E24 | 上表再插入 11、13、16、20、24、30、36、43、51、62、75、91 | ±5% | 常见 5% 电阻 |
| E96 | 96 个值，挨得很密 | ±1% | 精密分压、采样 |

要 50 kΩ 只能买 47 kΩ 或 51 kΩ——**阻值不是连续的，是货架上有的那些**。设计时先把值落到 E 系列上，能省掉一整轮寻料。

### 3.2 常用值速记

| 用途 | 常用值 |
| --- | --- |
| 上拉 / 下拉 | 4.7 kΩ、10 kΩ、100 kΩ |
| LED 限流 | 220 Ω、330 Ω、1 kΩ |
| 分压（ADC 采样） | 10 kΩ + 10 kΩ、100 kΩ + 100 kΩ |
| 串阻（抑制振铃） | 22 Ω、33 Ω、100 Ω |
| 电流检测 | 0.01 Ω、0.1 Ω（配合 1% 精度） |
| 去耦 | 100 nF（每只电源脚一只）、10 µF（每组一只） |
| 晶振负载 | 12 pF、20 pF（按晶体规格） |
| 电源滤波 | 4.7 µF、10 µF、22 µF、100 µF、470 µF |
| 常用电感 | 1 µH、4.7 µH、10 µH、22 µH |

### 3.3 单位换算与容差字母

| 换算 | 关系 |
| --- | --- |
| 电容 | 1 F = 10⁶ µF = 10⁹ nF = 10¹² pF |
| 电阻 | 1 MΩ = 1000 kΩ，1 kΩ = 1000 Ω，1 Ω = 1000 mΩ |
| 长度 | 1 mil = 0.0254 mm；1 mm ≈ 39.4 mil |
| 铜厚 | 1 oz 铜 ≈ 35 µm |
| 常用近似 | 40 mil ≈ 1 mm；100 mil = 2.54 mm |

| 字母 | B | C | D | F | G | J | K | M |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 容差 | ±0.1% | ±0.25% | ±0.5% | ±1% | ±2% | ±5% | ±10% | ±20% |

## 五、连接器间距族谱

| 系列 | 间距 | 常见用途 | 选型提示 |
| --- | --- | --- | --- |
| 排针 / 排母 | 2.54 mm | 模块、调试口、洞洞板 | 兼容性最好，占板面积也最大 |
| 排针 / 排母 | 2.0 mm / 1.27 mm | 小体积模块 | 与 2.54 不通用，别混买 |
| XH2.54 | 2.54 mm | 电源、电池、风扇 | 带扣，能过 3 A |
| PH2.0 | 2.0 mm | 电池、小电流电源 | 无扣，容易松 |
| ZH1.5 | 1.5 mm | 小信号、传感器 | 细线径，抗拉差 |
| GH1.25 | 1.25 mm | 电池、板内连线 | **带扣**，比 MX1.25 稳 |
| MX1.25 | 1.25 mm | 电池、小板间连线 | 无扣版本易脱，贴片座注意焊盘强度 |
| FPC / FFC | 0.5 mm / 1.0 mm | 屏幕、摄像头排线 | 触点方向（同向/反向）比间距更容易买错 |
| Type-C | 16P / 24P | USB 供电与数据 | 16P 只有 USB 2.0；24P 才有超高速与正反插全功能 |
| DC 电源座 | 5.5 × 2.1 / 5.5 × 2.5 | 适配器输入 | 2.1 与 2.5 内针不通用，插错会松 |
| 螺钉端子 | 3.5 / 3.81 / 5.08 mm | 大电流、现场接线 | 3.5 与 3.81 差 0.31 mm，**极易买错** |
| 牛角 / IDC | 2.54 mm | 排线、老设备 | 需要配套的压线头与工具 |
| 板对板（BTB） | 0.4 / 0.5 mm | 主板与子板 | 高度（合高）与间距一起选 |
| RJ45 / 卡座 | — | 网络、SD 卡 | 结构件，注意开孔与机械干涉 |

<Pitfall>连接器是「看着一样、插不上」的重灾区：`MX1.25` 与 `GH1.25` 都是 1.25 mm 间距但不通用；`3.5` 与 `3.81` 螺钉端子差 0.31 mm；FPC 的 0.5 mm 还分同向与反向触点。下单前一定核对**间距 + 针数 + 带不带扣 + 触点方向**四项。</Pitfall>

## 六、手焊与贴片的现实边界

| 情况 | 能不能手焊 | 怎么焊 |
| --- | --- | --- |
| 0805 及以上阻容 | 轻松 | 尖头烙铁，一边上锡一边扶正 |
| 0603 | 可以 | 镊子 + 助焊剂，先固定一端再补另一端 |
| 0402 / 0201 | 很难 | 热风枪 + 锡膏 + 放大镜 |
| SOT-23 / SOD-123 | 可以 | 拖焊，助焊剂要足 |
| SOP-8 / TSSOP | 可以 | 拖焊（多上锡再吸掉） |
| QFN / DFN | 需热风 | 钢网印锡膏 + 热风，底部焊盘必过孔 |
| BGA | 不建议 | 需返修台 + X 光检查 |
| 电解 / 直插件 | 容易 | 注意极性与高度 |
| 连接器 | 看封装 | 贴片座靠锡量，直插件靠机械固定 |

<Callout type="warn" title="丝印不要压在焊盘上">
丝印（白色字符层）压到焊盘会被阻焊开窗切掉，看起来是「字缺了一块」；更糟的是压到测试点或金手指上，影响焊接与外观。画封装时给丝印留 0.15 mm 以上的间距。
</Callout>

## 七、五秒自检

| 手上这个东西 | 立刻想到 |
| --- | --- |
| 本体印 `103` | 10 kΩ；四位数则是 1% 精密件 |
| 本体印 `104` | 100 nF = 0.1 µF，**不是** 104 pF |
| 本体印 `4R7` | 4.7 Ω 或 4.7 µH，看它是电阻还是电感 |
| 无色带无字的贴片小方块 | 大概率是 MLCC 或电阻，值只能查 BOM |
| 有粗横杠的黄色方块 | 钽电容，横杠端是**正极** |
| 侧面色带的圆柱 | 铝电解，色带端是**负极** |
| 一端有色带的黑色小方块 | 二极管，色带端是阴极 |
| 缺了一角的 LED | 缺角端是阴极；大焊盘是散热 |
| IC 一角有圆点或缺口 | 那是 pin1，装反必烧 |
| 0603 / 1608 | 同一件东西，一个是英制一个是公制 |
| 0402 | 0.4 × 0.2 mm，面积只有 0603 的十分之一 |
| QFN 底部发亮的方块 | 散热焊盘，必须打过孔焊到地 |
