## 一、位号（Reference Designator）：

### 1.1 规则只有三条

- **类别字母 + 序号**：`R1`、`C12`、`U3`。字母是类别，数字是这个类别里的第几个。
- **序号在整块板内唯一**：位号不是名字，是**索引**——BOM、贴片程序、测试工装、维修记录全靠它对齐。
- **多单元器件带后缀**：双运放 `U1A` / `U1B`，四与门 `U1A`…`U1D`，排阻 `RN1-1` … `RN1-4`。位号主体仍是 `U1` / `RN1`。

<KeyBox title="为什么不能随手改位号">
改一个位号，等于同时改：BOM 行、贴片程序坐标、AOI 检测点、测试工装、已经发出去的维修手册。

所以工程上有一条默契：<Mark>原理图评审冻结之后，位号只增不改</Mark>。返修板子上看到 `R7` 和图纸上的 `R7` 不是同一个器件（或者干脆不存在），是最容易把人带进坑里的事故。
</KeyBox>

### 1.2 无源与保护件

| 位号 | 器件 | 别名 / 子类 | 说明 |
| --- | --- | --- | --- |
| `R` | 电阻 Resistor | — | 最基础的一类；排阻另起 `RN`，不要写成 `R1`~`R4` 混在单电阻里 |
| `RN` `RA` | 排阻（电阻网络 / 阵列） | RP | 一个封装里 4/8 个电阻，公共端或独立端两种 |
| `RV` `RP` `VR` | 电位器 / 可调电阻 | W | 三端可调；国标常用 `RP`，EDA 库里多为 `RV` |
| `RT` `NTC` `PTC` | 热敏电阻 | TH | NTC 测温与抑制浪涌启动电流最常见 |
| `C` | 无极性电容 | — | 瓷片、C0G/NP0、X7R、薄膜 |
| `CP` `CD` | 极性电容 | EC | 电解 / 钽 / 固态；符号与丝印都必须标 `+` |
| `L` | 电感 | — | 功率电感、共模电感（共模也写 `LCM` / `FL`） |
| `FB` | 磁珠 Ferrite Bead | 部分图纸写 `L` | 直流几乎无损、高频变电阻；不能当储能电感用 |
| `F` `FU` | 熔断器 / 保险丝 | PPTC 自恢复 | 一次性熔断；自恢复保险也归这一类 |
| `RV` `MOV` `VDR` | 压敏电阻 | — | 与电位器撞字母：看封装（片式 0805/1206 多为压敏）和电路位置 |
| `T` `TR` | 变压器 | — | 反激、隔离电源、网络变压器 |
| `Y` `X` | 晶体（无源，2 脚） | XTAL | 必须配两个负载电容才起振 |
| `XO` `OSC` | 有源晶振（4 脚） | — | 自带振荡电路，脚位通常 EN / GND / OUT / VCC |
| `FID` | 光学基准点 | — | 只有焊盘与丝印，通常不进 BOM，但一定要标 |

### 1.3 半导体与有源件

| 位号 | 器件 | 别名 / 子类 | 说明 |
| --- | --- | --- | --- |
| `D` | 二极管 Diode | — | 整流、开关、肖特基；方向就是电流方向 |
| `LED` | 发光二极管 | 也常写 `D` | 写 `LED1` 更好搜、更好看丝印，推荐 |
| `ZD` `DZ` | 稳压（齐纳）二极管 | `Z` | 反向击穿工作，重点看功率与散热 |
| `TVS` | 瞬态抑制二极管 | 也写 `D` | 防静电 / 浪涌，单向与双向两种画法 |
| `Q` `VT` `V` | 三极管（BJT） | — | 国标用 `VT`，美标与 EDA 用 `Q` |
| `M` `Q` | MOSFET | — | 与「电机 `M`」撞字母；看有没有栅极符号来区分 |
| `U` `IC` | 集成电路 | — | MCU、运放、逻辑、电源芯片全在这一类 |
| `U` `VR` `PS` | 稳压器 / 电源模块 | — | LDO、DC-DC、隔离模块；多数 EDA 仍用 `U` |
| `BR` `DB` | 桥式整流器 / 桥堆 | `B` | 4 个二极管装一起，4 脚，`~` `~` `+` `−` |
| `SCR` `VS` | 晶闸管 / 可控硅 | TRIAC 双向 | 国标 `VS`，工控图纸常见 |
| `OPT` `OC` | 光耦 / 光电隔离 | 也写 `U` | 隔离栅与爬电距离是重点，不只是「一个芯片」 |

### 1.4 机电、连接与结构

| 位号 | 器件 | 别名 / 子类 | 说明 |
| --- | --- | --- | --- |
| `J` `CN` | 连接器 / 排针排母 | `XP` 插头、`XS` 插座、`XT` 端子 | EDA 里几乎全用 `J`；编号 `J1`、`J2` |
| `JP` | 跳线 / 短接点 | 0 Ω 电阻 | 调试期用来切功能，量产换成 0 Ω 或直接短接 |
| `SW` `SA` | 开关 | DIP 拨码开关 | 拨动、轻触、拨码都算 |
| `SB` | 按钮 | — | 国标把按钮单列，面板/操作件常用 |
| `K` `KA` | 继电器 | — | 小信号切换 |
| `KM` | 接触器 | — | 大电流、工业柜内，PCB 上少见 |
| `BZ` `HA` | 蜂鸣器 | 喇叭 `LS` / `SP` | 有源给电就响，无源要外部驱动方波 |
| `BT` `BAT` | 电池 / 电池座 | — | 座子与电芯分开算，BOM 里别搞混 |
| `M` | 电机 | 风扇 `FAN` / `BL` | 直流电机、散热风扇；与 MOSFET 撞字母 |
| `TP` | 测试点 Test Point | — | 探针与表笔的落点，量产测试靠它 |
| `H` `MH` `MTG` | 安装孔 / 固定孔 | — | 一般不贴片、不进 BOM，但图纸必须标 |
| `HL` | 指示灯 | — | 国标 `HL`，面板上的「电源灯」 |
| `PV` `PA` | 电压表 / 电流表 | — | 面板表头、监测点 |
| `ANT` `AR` | 天线 | — | 2.4G / 蜂窝模块外接，形状与长度都要算 |
| `QF` | 断路器 | — | 市电入口处，工业设备常见 |

### 1.5 五个最容易认错的

1. **`M` 是电机还是 MOSFET？** 无栅极符号、出现在电源入口 → 电机/风扇；三角形带箭头、贴着驱动芯片 → MOSFET。国产图纸里 MOSFET 更常见的写法是 `V` 或 `VT`。
2. **`D` / `LED` / `ZD` / `TVS` 都是二极管。** 图形几乎一样，差别只在阴极那条线怎么画（折钩 = 稳压，双向对顶 = TVS，外加箭头 = 发光）。
3. **`U` / `IC` / `VT` / `Q` / `T` 别混。** `U`、`IC` 指整块集成电路；`VT`、`Q` 指单管；`T` 是变压器——`T` 和 `TR` 在美标里也指变压器。
4. **排阻不是四个电阻。** `RN1` 是一个器件，BOM 一行；`RN1-1`…`RN1-4` 是它的四个单元，不是四个独立料号。
5. **`DNP` / `NI` / `NC`：位号在图上，板子上没有。** 意思是「位置留着、这次不贴」。BOM 里这两种状态必须写清楚，否则贴片厂会照单全贴。

## 三、一个符号是怎么画出来的

符号不标注尺寸，但它是在栅格上画出来的——这才是「为什么换个软件、换个库，连线还是能对齐」的原因。

<SymbolAnatomy no="附录 · 05" />

<Callout type="idea" title="自己画库元件时的自检">
引脚端点是否落在 100 mil 栅格上？位号与参数有没有压住引脚线？极性件的 `+`、二极管的方向、连接器的 1 脚点有没有标？

这三条对了，符号就「能用」；好看与否是其次。
</Callout>

## 四、国标与美标：图形的差别其实很小

<SymbolStandards no="附录 · 06" />

**图形符号**上，国标（GB/T 4728，等同采用 IEC 60617）与美标（ANSI/IEEE 315 一系）的差异基本集中在「电阻一族画矩形还是画锯齿」。二极管、三极管、电容、地符号这两套画法几乎一样。

**文字符号**（位号）才是真正的分歧点。同一张图上，同一个器件在两套标准里可能叫不同的字母：

| 器件 | 国标 / 国产图纸常见 | 美标 / EDA 默认 | 备注 |
| --- | --- | --- | --- |
| 三极管 | `VT` | `Q` | 最容易卡住的一个 |
| 集成电路 | `IC` | `U` | EDA 里几乎只有 `U` |
| 二极管 | `V` / `VD` | `D` | 国产图纸两种都见得到 |
| 晶闸管 | `VS` | `SCR` / `Q` | 工控图纸常见 `VS` |
| 熔断器 | `FU` | `F` | BOM 里两种写法都有 |
| 电位器 | `RP` / `W` | `RV` / `VR` | 与压敏电阻的 `RV` 撞车 |
| 按钮 | `SB` | `SW` | 国标把按钮与开关分开 |
| 开关 | `SA` | `SW` / `S` | — |
| 继电器 | `KA` | `K` | 接触器是 `KM` |
| 插头 / 插座 / 端子 | `XP` / `XS` / `XT` | `J` / `P` | EDA 一律 `J` |
| 指示灯 | `HL` | `LED` | 面板指示灯多用 `HL` |
| 蜂鸣器 | `HA` | `BZ` | — |
| 电动机 | `M` | `M` | 与 MOSFET 撞字母 |

<Callout type="success" title="实用判断顺序">
**图形认功能 → 位号认器件 → 网络名认连接。**

三者对不上时，以位号和网络名为准：图形可能画图的人自己随手改过，但位号进了 BOM、网络名进了网表，它们错不了（或者说，它们错了板子一定错）。
</Callout>

## 五、读一段真的原理图

把上面所有东西塞进一段能跑的电路：2 针接口进 3V3，一个去耦电容，一个电阻串 LED 做电源指示。

<SchematicWalkthrough no="附录 · 07" />

读图的固定顺序（照这个顺序走，几乎不会漏）：

1. **先找电源和地**：所有 `VCC_*` / `GND` 符号先认全，画出供电骨架。
2. **再看网络标签**：同名即同网络，标签是「隐形连线」。
3. **然后顺着信号走**：从连接器 / 芯片的某个脚出发，一路跟到下一个器件。
4. **最后查连接点**：两条线交叉处有没有实心点，决定了这里是不是真的连上。
5. **回头核对位号**：每个位号能不能在 BOM 里找到，封装对不对。

<Pitfall>
**交叉十字没有点 = 不相连。** 这是原理图里最贵的一个符号：漏看一个实心点，你会以为两路信号短在一起；多看一个点，你会漏掉一根实际存在的连线。

现代 EDA 里，真正连上的线一定是「线段端点落在另一条线上」并自动生成 junction；老图纸（尤其扫描件）里则全靠有没有那个点来判断。
</Pitfall>
