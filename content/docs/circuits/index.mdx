一块板里真正反复出现的电路就那么几类：怎么把电引进来、怎么把 12V 变成零点几伏的几百安、怎么安排上电顺序、怎么把信号送出板外。每换一个项目都要重画一遍，而图和经验分散在厂商参考设计、规范文档和老工程师的笔记里。

这一章按功能把它们分开写，一个功能一篇：什么条件下能直接用、什么条件下必须重画，参数怎么取，PCB 上要注意什么，出了问题怎么查。

## 一、按层看一块板

同样的层结构，换到不同产品上通常不用改，变的只是每层里填什么。比如工控主板的第 1 层是 24V 输入加几路 DCDC，第 2 层是网口与串口，道理一样。

| 层 | 作用 | 典型电路 |
| --- | --- | --- |
| 第 0 层 | 跨项目通用的积木 | 去耦、LDO、电平转换、复位、电流检测、ESD、端接、晶振 |
| 第 1 层 | 电源链，决定能不能带得动 | 输入与保护、分区配电、多相 VRM、存储器供电、辅助轨、上电时序 |
| 第 2 层 | 对外接口，决定能不能被认出来 | PCIe 金手指、HDMI、DP、USB-C、风扇 |
| 第 3 层 | 存储、时钟、配置 | SPI NOR、参考时钟树、复位与 strap |
| 第 4 层 | 监控与结构 | 温度、功耗监测、接地与屏蔽、测试点 |

### 第 0 层 · 通用积木

| 电路 | 做什么 | 关键端口 | 可调参数 |
| --- | --- | --- | --- |
| 去耦与滤波网络 | 给每个电源脚一条低阻抗回流 | VIN / GND / 负载 | 电流等级、噪声频段、电容配比 |
| LDO / 小功率 DCDC | 把 5V、3.3V 降到轨电压 | VIN / EN / PG / VOUT | 输入输出、电流、噪声、封装 |
| 电平转换 | 跨电源域传信号（1.8V ↔ 3.3V） | A 侧 / B 侧 / OE | 电压对、方向、速率、通道数 |
| 复位与延时 | 上电期间把芯片压住 | RST 入 / 出 | 延时、极性、去抖 |
| 电流检测 | 把电流变成可测的电压 | 分流两端 / 输出 | 高边或低边、量程、增益、带宽 |
| ESD / 浪涌防护 | 外露节点的泄放通道 | 被保护节点 / GND | 接口类型、钳位电压、结电容 |
| 端接 | 把反射收掉 | 信号入 / 端接网络 | 串联、并联、戴维南、AC 耦合、阻值 |
| 晶振与时钟 | 给芯片一个频率基准 | XTAL / CLK | 频率、负载电容、抖动要求 |
| 按键 / 跳线 / 配置电阻 | 给固件或人一个选择 | GPIO | 上下拉、默认态、去抖 |
| LED 指示 | 状态可视 | GPIO / 电源 | 颜色、驱动方式、亮度 |

### 第 1 层 · 电源链

| 电路 | 做什么 | 关键端口 | 可调参数 |
| --- | --- | --- | --- |
| [12V 输入与保护](/docs/circuits/12v-input) | 把外部电安全地引进来 | 连接器 → 12V 母线 | 路数、单路电流、连接器、保护等级 |
| 分区配电与保险 | 一路出事不拖垮其余各路 | 12V 母线 → 各电源域 | 分区数、熔断值 |
| [多相 VRM（核心供电）](/docs/circuits/vrm-multiphase) | 12V → 0.6～1.1V 的大电流 | PWM / IMON / 温度 → VCORE | 相数、每相电流、开关频率、拓扑 |
| 存储器供电（VDDQ / VDDCI） | 给颗粒一组干净的低压 | 12V → VDDQ / VDDCI | 电压组合、电流、是否共控制器 |
| VPP 供电 | 部分颗粒单独的写电压 | 12V → VPP 1.8V | 电流、纹波、滤波方案 |
| 辅助轨与电源树 | 说清谁给谁供电 | 12V / 3.3V → 1.8V AUX、PEX、显示 | 轨数、负载分配 |
| [上电时序与 PG 链](/docs/circuits/power-sequence) | 按顺序放开，按逆序关断 | 各轨 EN / PG / RESET | 顺序、延时、下电策略 |
| 电源监控与保护 | 越界就报、就关 | IMON / PMBus / OVP / OCP / OTP | 阈值、回差、锁存或自恢复 |
| 掉电泄放 | 断电时把电放干净 | 各轨 / GND | 泄放电流、时间常数 |

### 第 2 层 · 对外接口

| 电路 | 做什么 | 关键端口 | 可调参数 |
| --- | --- | --- | --- |
| [PCIe 金手指](/docs/circuits/pcie-finger) | 与主板之间的全部连接 | TX / RX、REFCLK、PERST#、PRSNT、SMBus、12V / 3.3V | 通道数、阻抗、耦合电容、ESD 方案 |
| HDMI 2.1 输出 | 一路显示送出去 | 4 lane、HPD、DDC、CEC、+5V | 速率、耦合方式、+5V 限流 |
| DP 1.4a 输出 | 另一路显示送出去 | 4 lane、AUX、HPD、+3.3V | 速率、耦合方式、ESD |
| USB-C / VirtualLink | 可选的一路复合接口 | CC、PD、mux、SBU | 是否支持 PD、mux 方案 |
| 风扇接口（4-pin） | 把热带走 | 12V、PWM、TACH | 风扇数量、驱动方式、堵转检测 |

### 第 3 层 · 存储、时钟与配置

| 电路 | 做什么 | 关键端口 | 可调参数 |
| --- | --- | --- | --- |
| SPI NOR + 双 BIOS | 存固件，且能回滚 | SPI 四线、CS#、WP#、切换 mux | 容量、电压、单或双、切换方式 |
| 参考时钟树 | 100 MHz 与像素时钟的分发 | REFCLK、XTAL、像素时钟 | 来源、buffer 数量、端接 |
| 复位与 strap 配置 | 决定这颗芯片被认成什么 | RESET#、strap、PRSNT 编码 | 配置字、默认值 |

### 第 4 层 · 监控与结构

| 电路 | 做什么 | 关键端口 | 可调参数 |
| --- | --- | --- | --- |
| 温度监测 | 风扇曲线与降频的依据 | 远程二极管、NTC、I2C | 测点数量、精度、摆放位置 |
| 功耗与电流监测链 | 把功耗墙变成数字 | 分流、放大、ADC / PMBus | 量程、采样率、上报格式 |
| 接地与屏蔽 | 定住整板的 EMC 底子 | 机箱地、螺丝孔、屏蔽罩弹片 | 接点数、单点或多点 |
| 调试与测试点 | 让问题能被测出来 | JTAG、UART、I2C、TP 阵 | 接口集合、测试点数量 |

## 二、电源链的形状

这些电路不是并列的清单，而是一棵树。电源链是数据面，时序与监控是横跨所有分支的控制面：

按树看电路，最大的好处是**隔离**：任何一处异常，先问它属于哪个节点，再看该节点的输入是否正常。「供电不对」这种判断之所以难查，往往就是因为没把电源链拆成有输入输出的节点。

动手时有三个位置最容易出错：

1. **接口没对齐**。上游的输出能力必须覆盖下游的输入需求，中间不留「大概够」的余量。
2. **控制面被拆散**。上电时序、PG 链、复位贯穿所有分支，不属于任何单一路电源；分散到各路电源里画，最后没人对整条顺序负责。
3. **全局约束被忽略**。叠层、地平面、散热是所有电路共享的前提，同一张原理图换板厚就可能完全不工作。

## 三、已经整理的四篇

| 电路 | 解决的问题 | 一句话结论 | 篇 |
| --- | --- | --- | --- |
| 12V 输入与保护 | 大电流路径 | 分路熔断、整层铜皮、过孔按 1 A/颗算 | [C01](/docs/circuits/12v-input) |
| 多相 VRM | 功率环路 | 环路面积最小、相间等长、sense 从负载取 | [C02](/docs/circuits/vrm-multiphase) |
| 上电时序与 PG 链 | 时序 | 级联不靠定时，下电必须主动逆序 | [C03](/docs/circuits/power-sequence) |
| PCIe 金手指 | 阻抗与规范 | 85 Ω、耦合电容只在 TX、PRSNT 决定通道数 | [C04](/docs/circuits/pcie-finger) |

其余各篇按同样的顺序写：先讲适用与不适用的边界，再给接口与参数，然后原理图、PCB 参考、器件降额，最后是测法与事故清单。

## 四、命名与图纸约定

同一套名字画到底，跨篇对图时才不用翻译。

| 项 | 约定 | 例子 |
| --- | --- | --- |
| 网络名 | 电压在前、用途在后，全大写 | `12V_IN`、`VCORE`、`PG_1V8`、`EN_VDDQ` |
| 位号 | 与[附录 A · 元件位号与原理图符号速查](/docs/appendix/symbols)一致 | `Q1`、`L2`、`U3` |
| 图号 | 每篇独立编号，C 代表电路 | `FIG · C01` |
| 参数表 | 每行标出越界后果，不只是推荐值 | 相数少于负载需求 → 单相过流、均流失效 |

传输线、回流、去耦的原理在[《传输线、阻抗与信号完整性》](/docs/pcb-design-manufacturing/signal-integrity)和[《接地、电源完整性与 EMC》](/docs/pcb-design-manufacturing/grounding-power-emc)里讲透了，这里只写具体电路怎么做、坑在哪。两边都写，最后一定会留下两个不一致的版本。
