插卡的接口参数大部分不由自己定：阻抗、脚位、耦合电容位置、金手指尺寸都在 PCI-SIG CEM 里规定好了。卡这一侧要做对的事不多，但每一条都是硬指标。

## 1 适用与不适用

**适用**：PCIe CEM 规范的插卡（add-in card，endpoint），x1～x16，Gen1～Gen6。

| 条件 | 说明 |
| --- | --- |
| 形态 | 标准金手指插卡，插在主机板上 |
| 角色 | 卡是 endpoint，主机是 root complex |
| 规范 | PCI-SIG CEM（卡机电规范），不是 PCIe Base 规范 |
| 板厚 | 1.6 mm 量级，与插槽簧片匹配 |

**不适用**：

| 情况 | 为什么不能套 | 该换成什么 |
| --- | --- | --- |
| 主板侧的插槽 | 阻抗预算、耦合电容位置、端接都在另一侧 | 按主板设计指南另写 |
| M.2 / U.2 / OCuLink | 连接器、SI 预算、供电定义都不同 | 各自的规范 |
| 线缆外接（PCIe over cable） | 通道损耗预算与均衡要求不同 | 线缆规范 + redriver |
| 专有夹层卡（mezzanine） | 没有 CEM 约束，脚位自定义 | 自定义连接器 |

<KeyBox title="这个接口的特殊性：一半参数不由你定">
别的电路可以自己定参数，这个不行——阻抗、脚位、耦合位置、时序要求、金手指尺寸都由 CEM 规定。你能决定的只有：**器件选型、布线质量、ESD 方案、以及有没有按规范核对**。

所以工作量集中在「必须等于」的那几个参数上，差一点点都算不合规。
</KeyBox>

## 2 接口定义

按功能分区，不按脚位罗列（脚位必须查 CEM 表格，x1 / x4 / x8 / x16 的分布不同）：

| 组 | 信号 | 方向 | 关键约束 |
| --- | --- | --- | --- |
| 主电源 | 12 V（A2 / A3 等） | 入 | 每脚 ≤ 5.5 A，整槽约 66 W |
| 主电源 | 3.3 V | 入 | 3 脚，给板内逻辑与部分 PHY |
| 待机电源 | 3.3 V aux | 入 | 主机待机时仍有电，给唤醒电路 |
| 地 | GND | — | 数量多且分散，是回流的主体 |
| 高速 | TX 对 ×N（卡发） | 出 | 需要 AC 耦合电容，85 Ω |
| 高速 | RX 对 ×N（卡收） | 入 | 不贴耦合电容，85 Ω |
| 参考时钟 | REFCLK+ / −（A13 / A14） | 入 | 100 MHz 差分，抖动与耦合位置按规范 |
| 复位 | PERST#（A11） | 入 | 异步复位，必须去抖 |
| 存在检测 | PRSNT1#（A1）/ PRSNT2# | 出 | 卡上短接，声明通道宽度 |
| 管理 | SMBus（SMCLK / SMDAT） | 双向 | 开漏，需要上拉 |
| 电源管理 | WAKE#、CLKREQ# | 双向 | 开漏，需要上拉 |
| 调试 | JTAG | — | 可选，量产可省 |

<Callout type="warn" title="PRSNT 编码：接错就是带宽掉一个数量级">
卡上把 `PRSNT1#` 与对应宽度的 `PRSNT2#` 脚短接，主机读这几个脚的电平来判断这张卡是 x1 / x4 / x8 / x16。

短接错（比如 x16 的卡只短了 x1 的那一对），主机会老老实实按 x1 训练——**能亮机、能显示，带宽只有 1/16**。

这种问题在功能测试里完全看不出来，只能靠链路速率/宽度读取或者吞吐测试发现。
</Callout>

## 3 参数表

这一张表里大部分是「必须等于」，不是「可选」：

| 参数 | 规范要求 | 越界后果 |
| --- | --- | --- |
| 差分阻抗 | **85 Ω ±10%** | 按 100 Ω 设计 → 回波损耗超标，训练降速甚至链路起不来 |
| AC 耦合电容 | 只贴在 **TX 侧**，100 nF（75–200 nF） | 贴错侧或两侧都贴 → 隔直位置错，链路不稳 |
| 对内失配 | ≤ 5 mil（同一对 P/N 之间） | 失配大 → 共模转差模，抖动与 EMI 同时上升 |
| 参考层 | 完整地平面，禁止跨分割 | 跨分割 → 阻抗突变，回流断裂 |
| 板厚 | 1.6 mm 量级（与插槽匹配） | 偏厚 → 插拔力大、簧片变形；偏薄 → 接触不良 |
| 金手指倒角 | 按 CEM 图纸，常见 20–30° | 倒角不足 → 插拔时刮伤插槽与 PCB |
| 镀层 | 硬金，约 0.4–1.0 µm（镍底层 2–5 µm） | 太薄 → 插拔几十次后露铜氧化 |
| 插拔寿命 | 按 CEM 要求（通常 ≥ 50 次） | 只在实验室插几次就验收 → 现场接触不良 |
| 12 V 铜皮 | 承载全部 12 V 脚电流之和 | 按单脚算 → 满载时插槽区域发热 |
| 边带 ESD | 超低容（≤ 0.5 pF 用于高速侧） | 用普通 TVS → 电容把眼图吃掉 |

<Callout type="idea" title="为什么是 85 Ω 而不是 100 Ω">
85 Ω 是 CEM 为插卡 + 插槽 + 主板的整条通道选定的折中值，它同时考虑了两侧 PCB 的可实现性与连接器处的阻抗台阶。

所以这不是「选一个更省电的值」的问题：**整条链路必须一致**。你在卡上按 100 Ω 做，主机按 85 Ω 做，交界处就是一次 15% 的阻抗跳变。

顺带提醒：USB、以太网、大多数 SerDes 是 100 Ω 或 90 Ω。**习惯最容易害人**，画板前先确认手上这根线是哪个标准。
</Callout>

## 4 原理图模板

<PcieFingerMap />

| 块 | 做法 | 注意 |
| --- | --- | --- |
| TX 对 | PHY → 100 nF ×2 → 金手指 | 电容成对、等值、位置对称；不要一对贴一对不贴 |
| RX 对 | 金手指 → PHY 直连 | 不要贴电容 |
| REFCLK | 金手指 → 时钟 buffer / PHY | 是否需要在卡上耦合，按 CEM 与平台指南确认 |
| PERST# | 金手指 → RC 滤波 → 施密特 → 芯片 | 上拉与去抖都要有 |
| PRSNT | 卡上短接，声明宽度 | 按 CEM 表格，逐脚核对 |
| SMBus / WAKE# / CLKREQ# | 开漏 + 上拉（常电域） | 待机时要能工作，上拉不能挂在会被关断的轨上 |
| 3.3 V aux | 单独一路，给唤醒与状态电路 | 与主 3.3 V 分开，避免被主电源开关影响 |
| ESD | 所有外露信号，含边带 | 放在信号进板内之前，越靠近金手指越好 |

## 5 PCB 参考

| 规则 | 数值 / 做法 | 违反后果 |
| --- | --- | --- |
| 差分走线层 | 优先内层（带状线），参考完整地 | 表层走线受阻焊不均影响，阻抗偏差大 |
| 过孔 | 尽量少；换层时成对，并在两侧加回流地孔 | 单侧换层 → 回流路径断裂，模态转换 |
| 对内等长 | ≤ 5 mil | 超差 → 共模噪声与抖动 |
| 金手指正下方 | 禁走线、禁铺铜 | 插拔磨损 + 阻抗不可控 |
| 金手指边缘 | 铜皮距板边留足爬电距离（按板厂能力） | 铺到板边 → 插拔时与插槽短路 |
| 12 V 与差分的间距 | ≥ 3× 线宽，必要时加地屏蔽 | 太近 → 电源噪声耦合进高速对 |
| 丝印 | 不得压金手指与焊盘 | 插拔时丝印磨损、污染触点 |
| 拼板 | 金手指区域不安排 V-cut / 铣槽经过 | 机械应力损伤触点 |

### 金手指工艺

| 项 | 做法 |
| --- | --- |
| 表面处理 | 硬金（电金），不接受沉金做触点 |
| 倒角 | 按 CEM 图纸加工，板厂默认倒角往往不够 |
| 阻焊 | 金手指开窗比焊盘略大，避免阻焊上金手指 |
| 出货保护 | 金手指贴保护膜，避免运输划伤 |

## 6 关键器件与降额

| 器件 | 选择判据 | 降额 |
| --- | --- | --- |
| AC 耦合电容 | 100 nF，C0G/X7R，0402 或 0201，耐压 ≥ 16 V，容差 ±10% | 电压 ≤ 50% 额定 |
| ESD 阵列 | 高速侧 ≤ 0.5 pF；边带可用普通 TVS | 钳位电压 ≤ 芯片绝对最大值 × 0.8 |
| 时钟 buffer | 附加抖动满足目标代际要求 | — |
| 复位监控 | 阈值精度、延时、手动复位 | 输入 ≤ 80% 额定 |
| 金手指（PCB 工艺） | 硬金厚度、倒角、板厚 | 按 CEM 而非板厂默认 |

## 7 验证与调试

| 验证项 | 怎么测 | 判据 |
| --- | --- | --- |
| 差分阻抗 | TDR，单端/差分都测 | 85 Ω ±10%，沿途无台阶 |
| 插损 / 回损 | VNA，测到目标代际的 Nyquist 频率 | 落在通道预算内 |
| 对内失配 | TDR 或相位测量 | ≤ 5 mil 等效长度差 |
| 链路宽度 / 速率 | 系统里读 `lspci -vv` 或厂商工具 | 与设计一致（这条能抓住 PRSNT 接错） |
| 眼图 | 误码仪或 PHY 内置 PRBS / 眼图扫描 | 满足目标代际的模板 |
| 插拔循环 | 50 次以上，每次读链路状态 | 无掉速、无误码、触点无可见磨损 |
| 边带电平 | 万用表 + 示波器看 PERST# 边沿 | 阈值正确，无抖动误触发 |
| ESD | 接触放电 ±2 kV（外露触点） | 无损坏、可自恢复 |

## 8 常见错误清单

| 错误 | 现象 | 根因 |
| --- | --- | --- |
| 差分按 100 Ω 设计 | 训练降速，重传率高 | 套了 USB / 以太网的习惯值 |
| TX、RX 两侧都贴了耦合电容 | 链路不稳、偶发不训 | 没搞清「电容在发送侧」 |
| 一对里只贴一颗电容 | 单端化，眼图塌 | 原理图复制时漏了 |
| PRSNT 短接错 | 能亮机，带宽只有 1/N | 按习惯接线，没逐脚核对 CEM |
| 金手指下方铺了铜做散热 | 插拔后阻抗漂移、偶发不认卡 | 把触点当散热面 |
| PERST# 直接进芯片 | 插拔抖动导致反复复位 | 没有 RC + 施密特 |
| 边带 ESD 用了大电容 TVS | 边带信号边沿变慢、误触发 | 只看钳位电压，没看结电容 |
| 金手指倒角按板厂默认 | 插拔刮伤、接触不良 | 图纸没标倒角要求 |
| REFCLK 与 TX 对长距离并行 | 时钟被数据噪声污染，抖动超标 | 布线时没做隔离与包地 |
