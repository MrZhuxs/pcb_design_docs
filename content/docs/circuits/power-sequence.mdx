多轨系统上电不是各自定时那么简单：谁先上、隔多久、什么条件满足才放开下一级，决定了芯片会不会在 IO 已带电而核心无电的状态下被反灌。时序横跨所有电源分支，不属于任何单独一路电源。

## 1 适用与不适用

**适用**：板上有 3 轨以上电源、且芯片对上电顺序或下电顺序有要求。

| 条件 | 说明 |
| --- | --- |
| 轨数 ≥ 3 | 两轨系统基本靠各自使能就够 |
| 芯片有顺序要求 | 典型是「IO 先于 core」，或者反过来，看芯片 PDG |
| 需要可控下电 | 掉电、重启、待机切换都要按顺序关 |
| 有复位信号 | 复位释放时机必须晚于电源稳定 |

**不适用**：

| 情况 | 为什么不能套 | 该换成什么 |
| --- | --- | --- |
| 芯片自带时序控制（集成 PMIC 已管好） | 外部再叠一层会打架 | 用 PMIC 的时序引擎，外部只做验收与监控 |
| 单轨或双轨 | 级联链带来的复杂度不划算 | 各自使能 + 一颗复位监控 |
| 需要热插拔上电（背板） | 时序只是其中一环，还要限流与短路穿越 | 热插拔控制器 + 时序 |
| 电源轨之间没有依赖关系 | 强行排序反而增加上电时间 | 直接并联使能 |

<KeyBox title="时序不是「上电慢一点更安全」">
顺序错了不会立刻炸，而是**批量性的偶发故障**：某批板子在低温下起不来、某些板子插拔几次后配置丢失、偶发无法识别。

这类问题最难查，因为它们不留下痕迹。所以时序要在设计阶段就写成表，并且真的用示波器抓出来对一遍。
</KeyBox>

## 2 接口定义

| 端口 | 方向 | 网络名 | 说明 |
| --- | --- | --- | --- |
| 前级电源有效 | 入 | `PG_1V8` 等各轨 PG | 开漏输出，需要上拉 |
| 使能 | 出 | `EN_VDDQ`、`EN_VCORE`… | 每轨一个，来自上一级的 PG 或延时电路 |
| 复位 | 出 | `PERST#`、`SYS_RESET#` | 全部 PG 有效后再延时释放 |
| 掉电检测 | 入 | `PWRGD_IN` / 12V 分压 | 母线掉电时抢先动作，不等电容放电 |
| 故障状态 | 出 | `SEQ_FAULT` | 任一级超时未建立 → 拉低全部使能 |
| 调试 | 出 | `TP_PG_*`、`TP_EN_*` | 每轨一对测试点，否则没法抓时序 |

## 3 参数表

代表性顺序（**以芯片 PDG 为准，这里只是方法示例**）：

| 序 | 轨 | 触发条件 | 典型延时 | 越界后果 |
| --- | --- | --- | --- | --- |
| 1 | 3.3 V AUX / 1.8 V | 12 V 建立 | 常电，不等 | 待机电路起不来 |
| 2 | VDDQ（存储器 IO） | `PG_1V8` 有效 | 1–5 ms | 早于 core → IO 带电而 core 无电，反灌闩锁 |
| 3 | VDDCI | `PG_VDDQ` 有效 | +1 ms | 与 VDDQ 同时 → 瞬态电流叠加，母线跌落 |
| 4 | VPP | `PG_VDDCI` 有效 | +1 ms | 晚于 core → 违反颗粒规格 |
| 5 | VCORE | `PG_VPP` 有效 | +1–10 ms | 早于 IO → 大电流冲击 IO 端 |
| 6 | RESET 释放 | 全部 PG 有效 | +1–10 ms | 提前释放 → 芯片在欠压状态启动，配置失败 |
| 下电 | 逆序：VCORE → VPP → VDDCI → VDDQ → 1V8 | 掉电检测触发 | 主动拉低使能 | 正序下电 → IO 仍带电，电流反灌 core |

| 参数 | 可选 | 推荐 | 越界后果 |
| --- | --- | --- | --- |
| 延时来源 | 芯片内建 / RC / 独立监控 IC | **芯片内建，其次监控 IC，最后才是 RC** | RC 延时误差 ±30%，批量后顺序可能反 |
| PG 上拉电阻 | 1–100 kΩ | 10 kΩ，1% | 过大 → 上升沿慢，被误判；过小 → 灌电流超标 |
| PG 上拉电源 | 被监控轨 / 常电轨 | **常电轨**（或专用逻辑电源） | 拉到被监控轨 → 该轨掉电时 PG 悬空，误判 |
| 复位去抖 | — | RC 100 nF + 10 kΩ 后接施密特 | 无去抖 → 插拔抖动导致反复复位 |
| 掉电检测阈值 | — | 母线 10.5–11 V 时触发 | 阈值过低 → 电容已放完才开始逆序，来不及 |
| 故障超时 | — | 每级 20–50 ms 未建立即判失败 | 无超时 → 卡在某级不报错，整机无显示 |

<Callout type="idea" title="上电正序、下电逆序的依据">
通用原则来自 CMOS 结构的寄生通路：IO 端带电而 core 无电时，ESD 二极管会把 IO 的电荷灌进 core 电源网络，形成闩锁电流。

所以**上电时先给 IO、后给 core；下电时先关 core、后关 IO**。具体到某颗芯片可能正好相反（少数器件要求 core 先），所以一定要查 PDG，不能凭这条原则硬套。
</Callout>

## 4 原理图模板

<PowerSequenceWave />

| 块 | 做法 | 注意 |
| --- | --- | --- |
| 级联触发 | `PG(n)` → `EN(n+1)` | 中间串延时电路时，延时在 EN 侧做，不要在 PG 侧钳位 |
| 延时 | 优先用芯片的 PG 延时寄存器 / Ramp 控制 | RC 直驱 EN 只做兜底 |
| 复位链 | 所有 PG 相与（或监控 IC 的 AND 输入） | 相与要在**驱动能力**足够的节点做，PG 是开漏 |
| 掉电检测 | 12V 分压 → 比较器 → 拉低全部 EN | 用常电供电的比较器，母线掉了它还在 |
| 故障锁存 | 超时或任一级掉 → 锁存并关全部 | 锁存比自恢复安全：避免反复重启掩盖问题 |
| 测试点 | 每轨 PG、每轨 EN 各一个 | 没有测试点，第 7 节的验证做不了 |

## 5 PCB 参考

| 规则 | 做法 | 违反后果 |
| --- | --- | --- |
| PG / EN 走线 | 远离 SW 节点、电感、12V 大电流铜皮 | 被开关噪声耦合 → 误判 PG、随机复位 |
| 上拉电阻位置 | 靠近接收端，不放在源头 | 长走线 + 弱上拉 → 上升沿被拖慢 |
| 掉电检测分压 | 靠近比较器，加 RC 滤波（10 kΩ + 100 nF） | 无滤波 → 母线纹波导致误触发 |
| 延时电容 | X7R，容差 ±10% | 用 Y5V → 容量随温度掉 60%，时序漂移 |
| 复位走线 | 单独走，不与其他信号并行 | 并行 → 复位被干扰，偶发重启 |
| 地 | 时序电路的地与功率地单点相连 | 多点相连 → 大电流回流串进比较器 |

## 6 关键器件与降额

| 器件 | 器件族 | 选择判据 | 降额 |
| --- | --- | --- | --- |
| 电源监控 / 时序 IC | 多路监控 + 可编程延时 | 路数、延时精度、是否带锁存 | 输入电压 ≤ 80% 额定 |
| 比较器 | 推挽或开漏 | 阈值精度、传播延迟、共模范围 | 输入不触及轨 |
| 施密特触发器 | 单门 | 阈值回差 ≥ 0.3 V | — |
| 上拉电阻 | 薄膜 1% | 容差优先于功率 | 功耗 ≤ 50% |
| 延时电容 | X7R / C0G | 容差与温漂 | 电压 ≤ 50% 额定 |
| 复位监控 | 专用复位 IC | 阈值精度、复位延时、手动复位输入 | — |

## 7 验证与调试

| 验证项 | 怎么测 | 判据 |
| --- | --- | --- |
| 上电顺序 | 4 通道示波器，各轨 + PG 同时抓 | 边沿顺序与设计表逐条一致 |
| 延时余量 | 实测每级延时 vs 规格 | 实际值落在规格区间中部，两侧各留 2× 余量 |
| 复位释放时机 | 抓最后一轨 PG 到 RESET 上升沿 | ≥ 规格要求的最小延时 |
| 下电逆序 | 断电瞬间抓全部轨 | 无反灌电流，顺序与设计一致 |
| 反复上下电 | 1000 次循环 | 无一次起不来、无闩锁 |
| 单轨失效注入 | 人为短路某一轨的 PG 到地 | 系统进入已知状态（重启或保持关断），不出现部分上电 |
| 极低温 / 极高温 | -10 °C 与 60 °C，各 100 次上电 | 时序不越界（这是 RC 延时的照妖镜） |
| 掉电检测 | 母线缓降（可调电源） | 在阈值处触发逆序，不早不晚 |

<Callout type="warn" title="时序必须用示波器抓，不能只看「能开机」">
「能开机」只证明顺序没到致命程度，不证明顺序正确。寄生通路与闩锁是概率事件，可能在第 1 次就炸，也可能在第 800 次插拔才出现。

四通道示波器一次只能抓 3 轨 + 1 个复位，多轨系统要分批抓，或者用带 MSO 逻辑通道的设备。
</Callout>

## 8 常见错误清单

| 错误 | 现象 | 根因 |
| --- | --- | --- |
| PG 上拉到被监控的那一轨 | 该轨掉电时 PG 状态悬空、偶发误判 | 上拉电源选错 |
| 用 RC 延时，而且用 Y5V 电容 | 量产批次时序漂移，低温起不来 | 容差与温漂没算 |
| 下电靠电容自然放电 | 顺序随机，偶发反灌损坏 | 没有主动逆序控制 |
| RESET 与最后一轨同时释放 | 偶发无法识别、配置失败 | 少了 1–10 ms 的稳定等待 |
| 多轨 PG 用一根线与起来，没有分级 | 出问题不知道是哪一轨 | 省了监控 IC 的输入路数 |
| EN 脚悬空（芯片内部无上拉） | 随机上电 / 上电电流异常 | 忘了加下拉 |
| PG 上拉电阻 100 kΩ | 上升沿慢，被后级当作未就绪 | 只看静态电平，没看边沿 |
| 忽略 PG 灌电流能力 | 多轨 PG 并在一起后电平拉不低 | 开漏输出并联时的灌电流与线上拉总和没算 |
