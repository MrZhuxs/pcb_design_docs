核心供电是整块板电流密度最高的地方：几百安、1 V 上下、瞬态在微秒级完成。相数、感量、环路面积、sense 取点这几个数定错，轻则掉压重启，重则烧功率级。

## 1 适用与不适用

**适用**：12V 输入、输出 0.5～1.2 V、电流 50～1000 A 的同步 buck，用 N 相并联把单相电流摊薄。

| 条件 | 范围 | 说明 |
| --- | --- | --- |
| 输入 / 输出 | 12 V → 0.5–1.2 V | 占空比约 4–10%，正是多相最合适的区间 |
| 负载电流 | 50–1000 A | 再小就没必要多相，再大要靠母排与更激进的散热 |
| 开关频率 | 300 kHz–1 MHz | 频率决定电感体积与开关损耗的取舍 |
| 负载性质 | 数字核心、存储器 IO | 允许较大的容性负载与快速跃变 |

**不适用**：

| 情况 | 为什么不能套 | 该换成什么 |
| --- | --- | --- |
| 电流 < 20 A | 多相的均流、布局与相数成本都不划算 | 单相 buck 或 LDO |
| 输入输出比 > 20:1 | 占空比过小，导通损耗与最小可控占空比都吃不消 | 两级变换（先降 5V 再降 core） |
| 需要升降压 / 双向 | buck 拓扑做不到 | 四开关 buck-boost |
| 输出噪声要求极高（模拟、RF、SerDes 电源） | 开关纹波靠电容压不下去 | 加 LDO 后级或换低噪声拓扑 |
| 负载电流变化极慢、要求极高精度（< 0.5%） | 多相均流误差与 DCR 温漂吃掉精度 | 线性后级 |

<KeyBox title="多相不是「并联几个 buck」">
把 N 个 buck 的输出直接并起来，电流会优先走阻抗最低的那一相——**布线阻抗差 20%，均流就差 20%**，而器件的电流余量通常只有 30%。

多相之所以成立，靠三件事同时做到：相间**等长**、器件**匹配**、控制器**闭环均流**（DCR 检测或每相 IMON）。缺一件，就会有一相先热、先过流、先失效。
</KeyBox>

## 2 接口定义

| 端口 | 方向 | 网络名 | 说明 |
| --- | --- | --- | --- |
| 输入 | 入 | `12V_IN` | 每相自带输入电容，不从远处借电 |
| 输出 | 出 | `VCORE` | 汇流排汇总后送到负载焊盘 |
| 远端 sense | 入 | `VCORE_SENSE+ / −` | 直接从**负载焊盘**取，差分、内层、避开 SW |
| PWM | 内部 | `PWM1..N` | 控制器 → 功率级，相邻相错开 360°/N |
| 使能 | 入 | `EN_VCORE` | 来自上电时序链（见[C03](/docs/circuits/power-sequence)） |
| 电流遥测 | 出 | `IMON_TOTAL`、`IMON1..N` | 总量上报固件，分相量用于均流与调试 |
| 温度 | 出 | `TSENSE_VRM` | 功率级附近 NTC，用于降频 |
| 电压设定 | 入 | `VID` / I2C / PMBus | 按核心工作点动态调压（AVS） |
| 状态 | 出 | `PG_VCORE`、`FAULT_VCORE`、`VR_HOT` | 时序链与故障上报 |

## 3 参数表

| 参数 | 可选范围 | 推荐取值 | 越界后果 |
| --- | --- | --- | --- |
| 相数 N | 4–24 | 稳态电流 / 每相 30–40 A（再留 1.3×） | 不足 → 单相过流、温升集中、效率塌；过多 → 轻载效率差、面积与成本上升 |
| 每相电流 | 30–90 A（按功率级等级） | ≤ 功率级额定 × 0.7 | 超标 → 电感饱和、功率级过热、均流彻底失效 |
| 开关频率 | 300 k–1 MHz | 400–600 kHz | 过高 → 开关与驱动损耗上升、驱动能力不够；过低 → 纹波大、瞬态差、电感体积大 |
| 每相感量 | 70–470 nH | 让纹波电流为相电流的 30–40% | 感量过大 → 瞬态跟不上；过小 → 纹波与涡流损耗大 |
| 电感饱和电流 | — | Isat > 1.4 × 相电流峰值 | 只按稳态选 → 瞬态过冲时饱和，电流失控 |
| 输出电容 | 陶瓷 + 聚合物 | 按 `ΔV = ΔI·ESL/…` 与容值双约束算 | 不足 → 跃变时欠压复位；只算容值不算 ESL → 高频尖峰压不住 |
| 均流误差 | — | < 10%（相电流） | 无闭环均流 → 可用电流打折 30% 以上 |
| 输出精度 | — | 静态 ±1%，含 DCR 温漂补偿 | 不补偿 DCR → 高温时输出电压偏低，性能掉 |
| 相位分布 | 均匀错相 | 相邻相 360°/N | 同相并联 → 输入纹波叠加，输入电容压力翻倍 |

<Callout type="idea" title="相数怎么定">
先算 `N ≥ I_max / (I_phase_rated × 0.7)`，再取偶数（便于对称布局与错相）。

例：稳态 400 A、瞬态 600 A、每相功率级额定 70 A → 按瞬态算 `600 / (70 × 0.7) ≈ 12.2` → 取 14 相。

反过来只按稳态算会得到 9 相 → 取 10，瞬态时每相要扛 60 A，正好在 0.86 倍额定的红区，纹波与温升都会超标。
</Callout>

## 4 原理图模板

<VrmPhaseTopology />

单相内部的连线顺序是固定的，不要重排：

```
12V → Cin → 功率级(HS/LS) → SW → L → Cout → 负载
                ↑BST          ↓
             自举电容      回流到 Cin(−)
```

| 块 | 关键取值 | 画图注意 |
| --- | --- | --- |
| 输入电容 | 每相 2×22 µF 陶瓷（X6S/X7R） | 紧贴功率级，与功率级之间的环路面积最小 |
| 功率级 | DrMOS / SPS，含上下管 + 驱动 | 散热焊盘必须打过孔阵列到内层铜 |
| 自举电容 | 0.1–1 µF，耐压 ≥ 25 V | 走线短、环路小，不能跨 SW |
| 电感 | 见参数表 | 下方内层禁走 sense / 时钟 |
| 输出电容 | 陶瓷 22–100 µF × N + 聚合物 | 分散在负载周围，不是集中在一处 |
| 远端 sense | 差分对，从负载焊盘取 | 内层走，两侧包地，避开所有 SW 铜皮 |
| IMON | 每相电流镜像 + 电阻到地 | 分相 IMON 是调试均流的唯一手段，别省 |

## 5 PCB 参考

### 功率环路：决定 EMI 与尖峰

| 规则 | 数值 | 违反后果 |
| --- | --- | --- |
| 输入电容到功率级 | ≤ 3 mm，同一层 | 环路电感大 → 开关尖峰打穿 HS，效率掉 2–5% |
| 功率环路包围面积 | 最小化，回路走内层地 | 面积大 → 辐射与传导干扰同时恶化 |
| SW 节点铜皮 | 只做到够过流，不外扩 | 铺成大片「为了散热」→ 变成天线，还会耦合进 sense |
| 相间等长 | 各相到输出汇流的路径差 ≤ 10% | 差 20% → 均流失效，某相先热 |
| 电感下方 | 内层完整地，禁走信号 | 走 sense / 时钟 → 电感漏磁直接串进反馈 |
| 功率级散热 | 焊盘下 4×4 过孔阵列（0.3 mm，间距 1 mm） | 过孔不足 → 结温超 125 °C，降额失效 |
| 输出汇流 | 整层铜皮 + 过孔阵列 | 走线过流 → 局部热点、压降吃掉精度 |
| sense 走线 | 内层、差分、包地、避开 SW 与电感 | 与 SW 并行 → 反馈被开关噪声调制，输出抖动 |

<Callout type="warn" title="sense 从哪取，比 sense 怎么走更重要">
从输出电容的焊盘取 sense 是最常见的错。大电流下，电容焊盘到负载焊盘之间那段铜皮的压降可能就有 20–50 mV——占 1 V 输出的 2–5%，足够让核心工作在错误的电压上。

**正确做法**：sense 差分对直接接到负载（芯片）的电源焊盘内侧，走内层。这是「远端 sense」的全部意义。
</Callout>

### 陶瓷电容的 DC bias：参数表里的容值不是实际容值

| 情况 | 标称 | 实际（1 V 偏置下常见） |
| --- | --- | --- |
| 0402 / 22 µF / 6.3 V X6S | 22 µF | 8–12 µF |
| 0603 / 47 µF / 4 V X6S | 47 µF | 20–30 µF |

按标称算瞬态，结果会差 2 倍。选型时必须查厂商的 DC bias 曲线，或者干脆按 50% 折算再做余量。

## 6 关键器件与降额

| 器件 | 器件族 | 降额 | 替代判据 |
| --- | --- | --- | --- |
| 功率级 | DrMOS / SPS | 电流 ≤ 70% 额定；结温 ≤ 105 °C | RDS(on)、热阻、IMON 精度、驱动能力 |
| 电感 | 一体成型 / 合金粉芯 | Isat > 1.4× 峰值；温升电流 > 1.2× 有效值 | DCR、软饱和特性、尺寸与高度 |
| 输出电容 | 陶瓷 X6S/X7R + 聚合物 | 电压 ≤ 80%；纹波电流 ≤ 70% | DC bias 曲线、ESR、ESL |
| 控制器 | 多相 PWM 控制器 | — | 最大相数、均流方式、VID 接口、环路补偿方式 |
| NTC | 0402 / 0603 | — | B 值容差、与功率级的距离一致性 |

## 7 验证与调试

| 验证项 | 怎么测 | 判据 |
| --- | --- | --- |
| 稳态纹波 | 输出电容处，20 MHz 带宽 | ≤ 1% 输出 |
| 负载跃变 | 10% → 100% → 10%，di/dt 按实际设计 | 跌落/过冲 ≤ ±3%，恢复时间符合环路设计 |
| 均流 | 每相 IMON 或电流探头 | 相间偏差 ≤ 10% |
| 效率曲线 | 10 / 25 / 50 / 75 / 100% 负载 | 峰值效率点落在常用工作区 |
| 温升 | 满载 30 min，热像仪 | 功率级结温 ≤ 105 °C，电感 ≤ 100 °C |
| 环路稳定性 | 注入法测 Bode（或看跃变波形阻尼） | 相位裕度 > 45°，增益裕度 > 10 dB |
| 短路保护 | 输出直接短路，看恢复 | 限流生效、无器件损坏、可自恢复 |
| 短路 → 空载反复 | 10 次 | 无闩锁、无参数漂移 |
| 上电冲击 | 冷启动看输入浪涌 | 不触发前级过流保护 |

<Callout type="info" title="均流怎么快速看">
没有电流探头也能粗判：满载跑 10 min，用热像仪看 N 个电感的温度分布。**最热的那相就是电流最大的那相**，温差超过 8–10 °C 基本可以确定均流有问题。

精确测量还是要读分相 IMON 或串电流探头——这也是为什么原理图里必须留分相 IMON。
</Callout>

## 8 常见错误清单

| 错误 | 现象 | 根因 |
| --- | --- | --- |
| 输入电容离功率级 5 mm 以上 | 开关尖峰高、效率偏低、HS 击穿 | 靠 12V 铜皮「供电」，环路电感太大 |
| SW 铜皮为了散热铺成一大片 | 辐射超标、sense 被污染 | 把辐射源当散热面 |
| 只放一颗输出电容，还在电感对侧 | 跃变时欠压复位 | 电容放在「有空位」的地方 |
| sense 从输出电容取 | 实际到芯片的电压低 20–50 mV | 没做远端 sense |
| 陶瓷电容按标称容值算瞬态 | 高低温瞬态都不够 | 忽略 DC bias 降容 |
| 相数与负载不匹配（轻载仍全相运行） | 待机效率差、发热 | 没有相数削减（phase shedding） |
| 只靠对称布线，没有闭环均流 | 某相温升明显偏高，寿命短 | 器件容差 + 布线误差叠加 |
| 电感只按稳态电流选 Isat | 瞬态过冲时饱和，电流失控 | 没留 1.4× 峰值余量 |
| DCR 未做温度补偿 | 高温时输出电压偏低、性能掉 | 铜阻随温度上升 0.4%/°C |
