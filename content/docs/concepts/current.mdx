## 一、电流

电流是电荷的定向移动。它是**单位时间内通过某一截面的电荷量**。

### 定义与单位

<Formula title="电流的定义">
  <FormulaRow k="I = dQ/dt">单位：安培（A），1 A = 1 C/s</FormulaRow>
</Formula>

电流是过程量（率），不是状态量（量）：

| | 电荷 Q | 电流 I |
| --- | --- | --- |
| 性质 | 状态量 | 过程量（率） |
| 单位 | 库仑 C | 安培 A = C/s |
| 能否储存 | **能**（电容、电池、静电） | **不能** |
| 能否被"用掉" | 能被中和、被带走 | **不能** |

安培定义的演变：

| 时期 | 定义方式 | 用什么定义 |
| --- | --- | --- |
| 2019 年之前 | 两根相距 1 m 的平行导线每米受力 **2×10⁻⁷ N** | 磁力 |
| 2019 年之后 | 固定元电荷 e = 1.602176634×10⁻¹⁹ C，1 A = 1 C/s | 电荷 |

工程上通常通过热、磁、化学效应间接测量电流。

### 电流产生的条件

- **有可以自由移动的电荷**（载流子）—— 见第二节
- **有电场来驱动这些电荷**（两点之间有电压）—— 见第三节
- **有闭合的回路**，让电荷能够持续流动而不堆积 —— 见第四节

### 电流的三种形式

- **传导电流**：真实电荷在导体或电解液中的定向移动。导线、走线、平面、电解液里的电流都属于这一类，它有焦耳热（I²R），也会带来质量迁移。
- **对流电流**：宏观带电体整体运动形成的电流，如静电喷涂、离子风。
- **位移电流**：变化的电场等效成的电流，出现在电容器内部、以及信号跨过平面缝隙的地方。它不产生焦耳热，也没有质量迁移。

### 有什么用

| 错误说法 | 为什么错 | 正确说法 |
| --- | --- | --- |
| "这个器件消耗电流" | 消耗的是功率，电流进多少出多少 | 器件消耗功率 W，工作电流是 I |
| "电源提供的电流用完了" | 电荷守恒，流出的必须全部流回 | 电源做的是推动电子 |
| "这个节点积累了很多电流" | 积累的是电荷 | 节点积累电荷就是电容的定义 |

### 参数与特性

| --- | --- |
| 1 A 对应的电子数 | **6.24×10¹⁸ 个/s** |

## 二、载流子与电流方向

能形成电流的带电粒子叫**载流子**。物质能否导电，取决于其中有没有载流子、以及载流子能否自由移动。

### 各类导体中的载流子

- **金属**：自由电子。铜、铝、银属于这一类，PCB 上的导体全部是金属。
- **电解液**：正离子和负离子同时参与导电。电池内部、电镀槽，以及 PCB 上的湿气与助焊剂残留都属于这一类。
- **半导体**：电子和空穴同时参与导电。硅、碳化硅、氮化镓器件属于这一类。
- **气体 / 真空**：电子和离子。电弧、等离子体、气体放电管属于这一类。
- **超导体**：库珀对（两个电子配对），需要低温。

**空穴**：价带里少了一个电子，就留下一个空位。旁边的电子挪进来填补，空位就相当于往反方向移动，所以这个空位表现得像一个带正电的载流子。

在能带图像里，它是**价带空态的准粒子描述**，不是真实的带正电粒子在飞。把它当作正电荷载流子处理在数学上与器件物理上是正确的，PN 结、二极管、三极管、MOSFET 的工作原理都基于此。

### 电流方向的规定

习惯上把正电荷移动的方向规定为电流方向。这个约定早于电子被发现，但它定义的是净电荷流，所以对任何载流子都成立：

| 场合 | 载流子实际流向 | 与电流方向的关系 |
| --- | --- | --- |
| 金属 | 电子（负） | 相反 |
| 电解液 | 正离子走向 − 极 | 相同 |
| 半导体 | 电子与空穴各走一边 | 两者都符合 |

计算磁场方向与霍尔电压时必须先分清"载流子方向"与"电流方向"，两者在金属中是相反的。

### 有什么用

两条相邻走线之间存在湿气和助焊剂残留时，这些杂质形成电解液。金属在阳极失去电子变成离子，离子在电场作用下迁移到阴极，重新得到电子析出。时间长会长出导电枝晶，使两条线之间逐渐短路。这就是 PCB 上的电化学迁移（ECM）与阳极导电丝（CAF）。

| 对策 | 物理依据 |
| --- | --- |
| 清洗助焊剂残留 | 没有电解液就没有离子迁移 |
| 加大间距、加防护涂层 | 削弱电场、阻断湿气路径 |
| 降低相邻网络的电位差 | 减小驱动离子迁移的电场 |

这是长期失效（几个月到几年）。低电压下只是速度更慢，不会不发生。

## 三、电流的驱动

电荷的定向移动是**电场力**作用的结果。

### 因果链

> **电源建立电场 → 电场对电荷施加力（F = qE）→ 电荷定向移动 → 形成电流。**

根本驱动力是电场；电压是电场的线积分（U = ∫E·dl），本身不是力。对集总电路，V = I·R 仍然是有效的描述方式。

### 导体内部的电场

- **纵向电场**沿着导线方向，作用是推动电子前进。1 A 通过 1 mm² 铜线时，纵向电场约 **17 mV/m**。
- **横向电场**存在于信号线与参考平面之间。3.3 V 的信号跨 0.2 mm 介质时，横向电场约 **16.5 kV/m**。

两者相差约 <Mark>10⁶ 倍</Mark>。

### 欧姆定律的两种形式

<Formula title="欧姆定律的两种形式" note="J 为电流密度（A/m²），σ 为电导率（S/m）">
  <FormulaRow k="V = I · R">宏观：一整段导体</FormulaRow>
  <FormulaRow k="J = σ · E">微观：导体里的每一点</FormulaRow>
</Formula>

欧姆定律不是因果律，而是一条本构关系 —— 它描述材料如何响应电场，就像弹簧的 F = kx 描述材料如何响应形变。它的适用边界是低频、线性、稳态。

纵向场强（铜 σ = 5.8×10⁷ S/m）：

<Formula title="算例 · 1 mm² 铜线走 1 A">
  <FormulaRow k="J = 1 A / 10⁻⁶ m² = 10⁶ A/m²">电流密度</FormulaRow>
  <FormulaRow k="E = J / σ = 10⁶ / 5.8×10⁷ ≈ 1.7×10⁻² V/m">≈ 17 mV/m</FormulaRow>
</Formula>

### 有什么用

走线上的主导物理量是信号与参考面之间的场（横向场比纵向场强 10⁶ 倍）。

| 结论 | 影响的设计 |
| --- | --- |
| 横向场决定辐射、串扰、阻抗 | 这些不能用"电路视角 + 电阻"算出来 |
| 纵向场只决定压降与损耗 | 直流压降用 R 计算 |
| 参考平面的完整性比走线电阻更重要 | 参考面是横向场的边界条件 |

同一个节点的两套模型：

| 关心的是 | 模型 | 敌人 | 解决手段 |
| --- | --- | --- | --- |
| 压降、功耗、线宽 | 稳态 | I·R | 加宽、加厚、铺铜 |
| 负载跳变、复位、振铃 | 瞬态 | L·di/dt | 减小回路面积 |

## 四、回路与回流路径

**电荷守恒**：电荷不能被创造，也不能被消灭，只能转移。所以流入某段导体的电流必须等于流出的电流。

### 三个层次

<Formula title="电荷守恒的三个尺度">
  <FormulaRow k="∇·J + ∂ρ/∂t = 0">微观：连续性方程</FormulaRow>
  <FormulaRow k="ΣI = 0">节点：稳态下的 KCL</FormulaRow>
  <FormulaRow k="每条信号线都有回流路径">板级：KCL 画在电路板上的样子</FormulaRow>
</Formula>

三级是同一条定理在不同尺度上的写法。

### 稳态与瞬态

- **稳态**下电流不会在节点堆积，流入多少就流出多少，所以每条信号线都必然有一条**回流路径**。
- **瞬态**下电荷确实会堆积，而节点积累电荷正是电容的定义：

<Formula title="节点电流不平衡会怎样" note="流入 1 A、流出 0.9 A：节点每秒多出 0.1 C，电压只能往上升">
  <FormulaRow k="C = Q / V   →   I = C · dV/dt">多余的电荷无处可去，就把节点电位顶上去</FormulaRow>
</Formula>

### 回流走哪条路

电流选择阻抗最小的路径，而阻抗由频率决定：

| 频率 | 主导项 | 回流走哪 |
| --- | --- | --- |
| 直流 / 低频 | R | **电阻最小**的路径（最短地线） |
| 高频 | ωL | **电感最小**的路径 → 回路面积最小 → 信号正下方的参考平面 |

高频回流贴着信号走，是因为回路面积最小意味着磁通最小、电感最小。

| 信号 | 主要频率分量 | 回流路径 |
| --- | --- | --- |

### 有什么用

回路面积同时决定电感 L、辐射强度、阻抗连续性。

| 做法 | 原因 |
| --- | --- |
| 参考平面不分割 | 回流不必绕行，回路面积保持最小 |
| 换层时配回流地过孔 | 给回流提供换层的通道 |
| DDR 走线区域禁止开槽 | 任何开槽都会强迫回流绕行 |

## 五、位移电流、去耦电容与 PDN

电容器两块板之间是绝缘的，没有任何电荷通过，但交流确实"通过"了它。麦克斯韦为此补上的一项就是**位移电流**。

### 定义

<Formula title="位移电流" note="加入位移电流之后，总电流密度才连续：∇·(J + ∂D/∂t) = 0">
  <FormulaRow k="J_d = ε · ∂E/∂t">变化的电场等效于一股电流</FormulaRow>
</Formula>

变化的电场等效于电流。电容器充电时，板上电荷在增加，板间电场在增强，这个增强的电场接续了回路里的电流。所以电容器不是"通了"电流，而是靠位移电流让回路保持闭合。

**总电流（传导 + 位移）的散度为零**，这保证了安培环路定理在时变场下依然自洽，也是"回路必须闭合"（第四节）在时变场下的完整表述。

### 电学特性

| | 直流 | 交流 / 高频 |
| --- | --- | --- |
| 板上电荷 | 充到稳定，不再变化 | 一直在充放 |
| 位移电流 | 无 | 有 |
| 表现 | **隔直流** | **通交流** |

### 去耦电容

| 现象 | 机制 |
| --- | --- |
| 电容隔直通交 | 直流下电场不变，没有位移电流；交流下电场在变，有 |
| 去耦电容能工作 | 它在局部闭合了回路，缩短了电荷要跑的距离 |
| 跨分割致命 | 回流要么绕行（回路面积暴涨），要么靠位移电流越过缝隙，形成缝隙天线直接辐射 |

<KeyBox title="必记">
去耦电容的四个要点：

- 效力取决于电容到芯片的**回路电感**，<Mark>不是容值</Mark>；
- 地端要就近打孔接参考平面，回流走的是平面，不是那根细线；
- 大小容值并联使用，大容值电容封装通常更大、ESL 更大，高频阻抗反而更差；
- 容值小但贴得极近的电容负责高频。
</KeyBox>

跨分割在低频没有影响（回流本来就走最小电阻路径，位移电流也极小），频率升高后才成为问题。

### PDN 的目标阻抗

把上面几条合成一个可算的指标：**在关注频段内，PDN 阻抗全程低于目标阻抗**。

<Formula title="PDN 目标阻抗">
  <FormulaRow k="Z_target = ΔV_允许 / ΔI">允许的电压波动 ÷ 最大电流跳变</FormulaRow>
</Formula>

| 参数 | 示例 |
| --- | --- |
| 电源轨 | 1.2 V |
| 允许波动 ±3% | ±36 mV |
| 负载跳变 | 10 A |
| **目标阻抗** | <Mark>36 mV / 10 A = 3.6 mΩ</Mark> |

不同频段由不同的元件负责：

| 频段 | 主要威胁 | 负责的元件 | 做法 |
| --- | --- | --- | --- |
| DC ~ 100 kHz | 直流压降、负载调整率 | 电源模块、大容值电容 | 铺铜与平面、远端采样 |
| 100 kHz ~ 1 MHz | 开关频率纹波 | 中容值陶瓷（1~10 µF） | 每路电源就近一颗 |
| 1 MHz ~ 10 MHz | 负载跳变的低频分量 | 小容值陶瓷（0.1~1 µF） | 紧贴芯片电源脚 |
| 10 MHz ~ 100 MHz | PDN 阻抗峰、平面谐振 | 极小容值（10~100 nF）、平面电容 | 多颗并联、缩短回路 |
| > 100 MHz | 封装与芯片内部去耦 | 片上去耦、封装内电容 | PCB 层面已难改善 |

## 六、载流能力与压降

### 三个约束

- **压降**：导线有电阻，电流流过就会损失电压，导致负载端电压不足。低电压大电流的电源轨上最先出现。
- **温升**：电流在导线和基板上产生热量，用**载流能力**衡量。中等电流、散热差时成为瓶颈。
- **机械与失效**：焊点蠕变、基板碳化、铜熔断。只在极端过载与短路时出现。

### 压降的计算

<Mark>必须按最高工作温度算</Mark>，不能只算室温：

| 步骤 | 内容 |
| --- | --- |
| 1 | 取最高工作温度下的电阻率。铜：100°C 约为 20°C 的 <Mark>1.4 倍</Mark> |
| 2 | 用 R = ρ·L/(w·t) 算走线电阻 |
| 3 | 乘该轨最大工作电流，得到压降 |
| 4 | 与允许波动比较（12 V ±3% = ±360 mV；1.2 V ±3% = ±36 mV） |

示例：1 oz 铜、0.25 mm 宽、100 mm 长的走线，室温 R ≈ 0.197 Ω；按 100°C 修正后约 <Mark>0.28 Ω</Mark>，走 1 A 时压降约 <Mark>280 mV</Mark>。

| 电源轨 | 280 mV 占比 | 结论 |
| --- | --- | --- |
| 12 V（±3% = 360 mV） | 2.3% | 可接受 |
| **1.2 V（±3% = 36 mV）** | <Mark>23%</Mark> | **严重超标** |

| 要点 | 做法 |
| --- | --- |
| 低压大电流轨（0.8 / 1.1 V） | 用铺铜或平面，不用细走线 |
| 反馈点 | 取在负载端（远端采样），否则负载端压降无人管 |
| 计算温度 | 一律按最高工作温度，不按 20°C |

由公式得到的三个关系：

| 关系 | 系数 | 原因 |
| --- | --- | --- |
| 线宽加倍 → 电流 | **×1.65**（2^0.725） | 散热面积也同时增加，所以是次线性关系 |
| 温升翻倍 → 电流 | **×1.36**（2^0.44） | 散热增长快于温升 |
| 内层相对外层 | **×0.5** | 内层被介质包住，热量只能靠铜传导 |

修正因素：周围有其他发热器件、多根大电流走线并行、铜厚（2 oz 约 ×1.7，不是 ×2）、铺铜。

### 过孔载流

<Formula title="一个过孔的导电截面" note="孔径 0.3 mm、孔壁镀铜 25 µm">
  <FormulaRow k="A = π · d · t = π × 0.3 mm × 0.025 mm">≈ 0.024 mm²（约 36 mil²）</FormulaRow>
</Formula>

| 要点 | 说明 |
| --- | --- |
| 经验量级 | 常规过孔约 <Mark>1 A</Mark>，但<Pitfall>这个值与孔径、镀铜厚度、允许温升、是否直接连平面强相关</Pitfall> |
| 正确做法 | **按实际导电截面与散热条件重算**，不要把 1 A 当固定值 |

| 电流拥挤 | 电流从平面进入过孔时会挤在孔的边缘，等效电阻大于按截面计算的值 |
| 数量 | 每 1 A 至少 1 个（保守取 2 个），并均匀分布在线宽上 |

### 失效温度顺序

| 温度 | 现象 |
| --- | --- |
| 100 ~ 130°C | 焊点蠕变、焊料长期可靠性下降 |
| **130 ~ 180°C** | **FR-4 达到玻璃化转变温度 Tg → 软化、分层** |
| 200°C 以上 | 基板碳化变色，碳化物开始导电，形成意外的漏电通路 |
| 1085°C | 铜熔化 |

铜的熔点比 FR-4 的 Tg 高一个数量级，所以走线烧断之前基板已经损坏，中间还有一段较宽的"发热但不烧"的区间。

## 七、电流在时间上的形态

### 四种形态

- **直流（DC）**：大小和方向都不变。电源轨、偏置电压属于这一类。
- **交流（AC）/ 正弦**：周期性地改变大小和方向。工频、时钟、射频信号属于这一类。
- **脉冲 / PWM**：方波，有固定的占空比。开关电源、LED 调光、电机驱动属于这一类。
- **单次浪涌**：上电瞬间出现的大尖峰。容性负载上电、雷击浪涌属于这一类。

### 同一个波形的三个值

- **峰值 I_pk**：波形能达到的最大瞬时值，决定器件的应力、磁饱和与瞬态压降。
- **平均值 I_avg**：一个周期内电流的平均，决定转移的电荷量。
- **有效值 I_rms**：与它发热效果相同的直流值，决定发热与温升。

### 有什么用

| 关心的量 | 用哪个值 | 依据 |
| --- | --- | --- |
| 发热、温升、线宽、器件损耗 | **有效值 RMS** | P = I_rms² · R |
| 电荷量、容量、续航 | **平均值** | Q = I_avg · t |
| 器件应力、饱和、瞬态压降 | **峰值** | V = L·di/dt；磁饱和 |
| 过流保护、熔断 | RMS（热）+ 时间-电流曲线 | 熔断是热积累过程 |

| 抑制手段 | 原理 | 缺点 |
| --- | --- | --- |

短路电流需要用于：保险丝分断能力、TVS 选型、母排机械应力、电源限流点设置。

## 八、di/dt

### 两条压降公式

<Formula title="两种压降" note="L = 1 nH、di/dt = 1 A/ns 时，瞬态压降就是 1 V——已经吃掉一颗 1 V 内核的全部余量">
  <FormulaRow k="ΔV = I · R">直流压降：走线、过孔、连接器的电阻</FormulaRow>
  <FormulaRow k="ΔV = L · di/dt">瞬态压降：回路电感对电流变化率的响应</FormulaRow>
</Formula>

### 电学特性

直流压降由电阻决定，可以用加宽、加厚、铺铜来减小。
瞬态压降由**回路电感**和**电流变化率**决定 —— 加宽铜皮减小的是 R，不是 L，所以对它无效。

### 有什么用

| 场合 | 电流 | di/dt | 回路面积 | 主要矛盾 |
| --- | --- | --- | --- | --- |
| **DC-DC 输入回路** | 大 | 极大 | 必须最小 | **回路面积**（不是电流大小） |
| DC-DC 输出回路 | 大 | 大 | 必须最小 | 回路面积 |
| 处理器核心供电 | 极大 | 极大 | 平面 + 就近去耦 | 回路面积 / PDN 阻抗 |
| 普通 GPIO | 小 | 中 | 一般 | — |
| 高速差分链路 | 小 | 大 | 参考平面完整 | 阻抗连续性 |

DC-DC 输入与输出回路的难点不是电流大，而是开关瞬间的 di/dt 大，所以这两处要求回路面积最小。

### 参数与特性

| 量 | 数值 / 说明 |
| --- | --- |
| 1 mm 走线的回路电感量级 | <Mark>约 0.5 ~ 1 nH/mm（视回流路径）</Mark> |
| 1 nH × 1 A/ns | <Mark>1 V</Mark> 瞬态压降 |
| 现代处理器负载跳变量级 | 每 A/ns 级 |
| 有效手段 | 减小回路面积（不是加宽铜皮） |

## 九、电流流过导体的三个后果

### 热效应

<Formula>
  <FormulaRow k="P = I² · R">功率，单位 W；同一根线上电流翻倍，发热变成四倍</FormulaRow>
</Formula>

- 电流加倍，发热变为 4 倍；
- 温度升高使铜的电阻率上升（100°C 约为 20°C 的 1.4 倍），发热进一步增加，形成正反馈。散热差的结构（如内层的细长走线）恶化最明显。

### 磁效应

<Formula>
  <FormulaRow k="L = Φ / I">电感 = 每安培建立的磁通量</FormulaRow>
</Formula>

电感是回路的属性，不是元件的属性。同一根走线，回流路径不同，电感可以差几十倍。

磁场如何产生、平行电流之间的受力规律、磁畴与磁铁的成因、串扰两条耦合通道的物理来源，见《原子、质子、电子与四种力》篇第九节。

### 机械力

两股平行电流之间有力的作用（公式见《原子》篇第九节）：

<Formula title="平行导体的电动力" note="两平行母排、间距 1 cm、各通 10 kA：F/L = (4π×10⁻⁷ × 10⁸) / (2π × 0.01) = 2000 N/m">
  <FormulaRow k="F/L = μ₀ · I₁·I₂ / (2π·d)">单位长度受力，单位 N/m；电流同向相吸、反向相斥</FormulaRow>

### 有什么用

| 效应 | 对应设计问题 |
| --- | --- |
| 热（I²R） | 线宽、铜厚、功率降额、散热 |
| 磁（L = Φ/I） | 串扰、共模扼流圈、DC-DC 电感 |
| 机械力（F/L） | 短路时的母排固定与支撑 |

短路电流的机械力对策：用叠层母排（正负母排紧贴叠放），既让磁场互相抵消，又同时减小了电感和机械力；再加密固定点，缩短母排的自由跨度。

## 十、测量电流

工程上通常通过热、磁、化学效应间接测量电流，各种方法各依赖其中一种。

### 各类方法的原理与边界

| 方法 | 原理 | 能测直流 | 优点 | 限制 |
| --- | --- | --- | --- | --- |
| **分流电阻** | 测 V = I·R | ✅ | 便宜、精确、带宽高 | 引入压降与功耗；需 Kelvin 接法；有寄生电感 |
| 霍尔传感器 | 测磁场 | ✅ | 隔离、可测大电流 | 零漂、温漂、带宽低（几十 kHz） |
| 电流互感器 CT | 磁场耦合 | ❌ | 隔离、几乎无损耗 | 只能交流；会饱和 |
| 罗氏线圈 | dI/dt | ❌ | 高带宽、无磁芯饱和 | 需积分器 |
| 电流钳 | 同 CT | 视型号 | 不断线测量 | 直流需霍尔 |
| 磁通门 | 磁饱和检测 | ✅ | 高精度、低漂移 | 贵、带宽有限 |

**微弱电流的下限**：测量 nA 以下电流时，除了热噪声（见《原子》篇第七节），还会遇到散粒噪声 —— 电子是一个一个通过的，电流本身不是完全平滑的量。这是这类测量的物理下限，不是仪器精度问题。

### 有什么用

上电调试（Bring-up）的标准配置是：可调限流电源 + 分流电阻 + 示波器。

| 要点 | 做法 | 原因 |
| --- | --- | --- |
| 四线 Kelvin 接法 | 电流路径与采样路径分开引线 | 否则走线电阻被算入采样，误差可达 10% |
| 选小阻值 | 让压降远小于电路工作电压 | 引入的压降会改变电路行为 |
| 选低感封装 | 大 di/dt 场景用低感或四端子封装 | 寄生电感产生电压尖峰，会被误读为电流尖峰 |
| 位置 | 采样点紧靠电阻焊盘 | 远离了就等于把走线电阻加进采样 |

### 三个测量陷阱

- <Pitfall>用普通示波器探头测分流电阻</Pitfall>：探头的地线夹是接到示波器机壳地的，把它夹到电路上任意一点，就等于给电路接了一根地线，会形成地环路、可能短路掉被测的那一段，还可能烧掉探头。正确做法是用差分探头或隔离探头。
- <Pitfall>用万用表串联测电流</Pitfall>：万用表测电流时是串联的，而且内阻不为零。在低压大电流电路上，这几百毫欧会带来明显压降，电路可能因此启动失败。
- <Pitfall>用电流钳测共模电流时只夹一根线</Pitfall>：只夹一根线读到的是那根线的差模电流，必须按上图把整束线全部夹进去。

## 十一、高频下的电流

### 趋肤效应

导体内部的交变磁场会感应出涡流，把导体中心的电流抵消掉，于是电流集中到导体表面附近。

它改变的是**电流密度的分布**，导体的总电流不变 —— 不是"电子被挤到表面飞出去了"。

### 邻近效应

相邻导体的磁场会把电流挤到导线的一侧。

- **趋肤效应**来自导线自身的磁场，使电流集中在表面；
- **邻近效应**来自相邻导体的磁场，使电流进一步集中在靠近或远离邻线的那一侧。

### 有什么用

| 场合 | 表现 |
| --- | --- |
| 平面与走线之间 | 电流集中在走线正下方 |
| 差分对内部 | 两线电流方向相反，互相把对方电流挤到内侧 → 有效截面减小 → 损耗上升（紧耦合损耗高于松耦合） |
| 相邻走线 | 互相推挤电流分布 → 交流电阻上升 |

三条结论：

| 结论 | 说明 |
| --- | --- |
| 厚铜不帮高频 | 1 GHz 时趋肤深度只有 2 µm，2 oz 与 1 oz 的高频电阻几乎相同 |
| 高频损耗的两个战场 | 介质 Df（介质损耗）与铜箔表面粗糙度（导体损耗） |
| 趋肤不是截面积失效 | 它改变的是电流分布，不是把铜变小 |

### 参数与特性

<Formula title="趋肤深度" note="铜在室温下的简化式：δ(µm) ≈ 66 / √(f 以 MHz 计)">
  <FormulaRow k="δ = √( 2 / (ω · μ · σ) )">严格式：角频率、磁导率、电导率</FormulaRow>
</Formula>

<Approx>
该简化式针对**室温铜、非磁性材料**。温度升高会降低电导率，使趋肤深度变大（损耗略降）；铁磁性镀层（如镍）不适用。
</Approx>

| 频率 | 铜的趋肤深度 | 与 1 oz 铜（35 µm）的关系 |
| --- | --- | --- |
| 1 kHz | 2.1 mm | 全厚 |
| 100 kHz | 0.21 mm | 全厚 |
| 1 MHz | 66 µm | 全厚 |
| **~3.5 MHz** | **35 µm** | **分界点（1 oz 铜的直流工作上限）** |
| 10 MHz | 21 µm | 用 60% 截面 |
| 100 MHz | 6.6 µm | 用 19% |
| 1 GHz | 2.1 µm | 用 6% |

### 传输线与集总参数的分界

高频之后，走线不再是"一根导线"，而是一段传输线。判据是**走线长度与上升沿空间长度之比**：

<Formula title="什么时候必须按传输线处理">
  <FormulaRow k="上升沿空间长度 = t_r × v">v = c / √Dk，信号在边沿时间内跑过的距离</FormulaRow>
  <FormulaRow k="走线长度 > 上升沿空间长度的 1/6">超过这个比例，反射与振铃就不能再忽略</FormulaRow>
</Formula>

| 例 | 计算 |
| --- | --- |
| 上升时间 t_r | 1 ns |
| FR-4 中信号速度 | 15 cm/ns |
| 上升沿空间长度 | 15 cm |
| **1/6 判据** | <Mark>2.5 cm 以上就要按传输线处理</Mark> |

所以 10 MHz 的方波，只要边沿是 1 ns，几厘米的走线就已经是"高速"了。决定这个分界的是**边沿速度**，不是时钟频率（与第四节回流分界频率的结论一致）。

### 高频与低频的表述对照

| 低频的说法 | 高频的准确说法 |
| --- | --- |
| 电流在导线里流动 | 场在介质中传播，导体只提供边界条件 |
| 电流需要回流路径 | 回路面积决定电感，电感决定瞬态压降与辐射 |
| 电容器隔直流 | 位移电流接续回路；直流下没有位移电流 |
| 走线的电阻决定压降 | 直流压降看 R，瞬态压降看 L·di/dt |
| 减小耦合要拉开距离 | 拉开距离 + 参考平面 + 屏蔽，三者并用 |
| 电流走阻抗最小的路径 | 低频 = 最小电阻；高频 = 最小电感（最小回路面积） |

## 十二、板上八种电流

| # | 电流类型 | 典型量级 | 真正的约束 | 设计手段 |
| --- | --- | --- | --- | --- |
| 1 | 电源主电流 | 0.1 ~ 20 A | 压降（早于温升）、温升 | 线宽、铜厚、铺铜、过孔数量 |
| 2 | **瞬态电流 di/dt** | 每 A/ns 量级 | **L·di/dt 瞬态压降** | **回路面积最小**、就近去耦、完整平面 |
| 3 | 信号电流 | mA 级 | 阻抗连续性（不是大小） | 参考平面完整、阻抗控制 |
| 4 | **回流电流** | 与信号等量 | **回路面积（比信号幅度更关键）** | 不跨分割、换层配回流过孔 |
| 5 | 浪涌 / 冲击电流 | 稳态的 5 ~ 20 倍 | 能量 I²t、器件应力 | 软启动、NTC、保险丝选型 |
| 6 | 泄漏电流 | nA ~ µA | 高阻节点的噪声裕量与漂移 | 清洗、防护涂层、降低电位差 |
| 7 | 共模电流 | µA 级 | EMC（辐射与传导发射） | 共模扼流圈、Y 电容、减小回路面积 |
| 8 | 短路电流 | kA 级 | 机械力、保险丝分断能力 | 保险丝、TVS、限流、母排固定 |

<KeyBox title="必记">
第 3 类（信号电流）只有 mA 级，看起来无害；但决定信号质量的是第 4 类的<Mark>回流路径完整性</Mark>。信号幅度本身几乎从来不是问题，回流走得好不好才是。
</KeyBox>

**第 1 类与第 2 类的区别**：

| | 电流大（1 类） | 电流变得快（2 类） |
| --- | --- | --- |
| 敌人 | 压降 I·R、温升 | 瞬态压降 L·di/dt、辐射 |
| 手段 | 加宽、加厚、铺铜 | **减小回路面积** |
| 表现 | 电压偏低、发烫 | 随机复位、逻辑错误、EMC 超标 |
| 发现时机 | 万用表一测即可 | 特定负载跳变下偶发 |

### 设计检查清单

**回流**

- [ ] 每条信号线的回流路径在 PCB 上能**指出来**
- [ ] 信号不跨分割（参考平面无开槽、无被其他信号切断）
- [ ] 换层处配了回流地过孔（换层 ≤ 2 次）
- [ ] DDR 走线区域下方禁止开槽

**载流与压降**

- [ ] 载流按 IPC-2221 估算后，再用规范或板厂工艺表复核
- [ ] 内层按外层的一半计算
- [ ] 压降在**最高工作温度**下计算（铜 100°C 取 1.4 倍）
- [ ] 低压大电流轨（0.8 / 1.1 V）用铺铜或平面，不用细走线
- [ ] 远端采样：反馈点取在负载端
- [ ] 过孔数量按电流均摊（每 1 A ≥ 1 个），并均匀分布

**di/dt 与 PDN**

- [ ] DC-DC 输入与输出回路面积最小
- [ ] 去耦电容就近，地端直接打孔接参考平面
- [ ] 大小容值并联覆盖各频段
- [ ] PDN 阻抗在关注频段内低于 Z_target = ΔV_允许 / ΔI

**浪涌与保护**

- [ ] 计算上电浪涌 I ≈ C·ΔV/Δt
- [ ] 保险丝同时满足稳态降额与浪涌 I²t
- [ ] 评估短路电流（保险丝分断能力、母排固定）

**EMC**

- [ ] 减小回路面积（同时改善 SI 与辐射）
- [ ] 共模电流路径已识别；必要时加共模扼流圈与 Y 电容
- [ ] 时钟与开关节点远离开口、连接器、线缆

**测量**

- [ ] 分流电阻用四线 Kelvin，选低感封装
- [ ] 用差分或隔离探头，不用普通探头测分流电阻
- [ ] 测共模电流时把整束线一起夹入
