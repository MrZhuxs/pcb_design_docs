## 一、PCB 设计到底是什么

在消费电子产品中，从一台智能手机、一只TWS耳机，到一个智能插座，其核心功能都依赖于印刷电路板（PCB）的稳定运行。
对于硬件工程师来说，理解PCB设计不仅是完成设计任务的前提，更是掌握系统稳定性、电磁兼容性、生产效率的关键一环。
很多人把“画板子”等同于“连上线”，但一块能工作的板和一块**能量产、能过认证、能稳定跑五年的板**，中间隔着一整条工程链。

从能力层级来看，PCB 设计大致是这样一条阶梯：

| 层级 | 典型能力 | 典型产品 | 需要跨过的门槛 |
| --- | --- | --- | --- |
| L1 入门 | 原理图 → 两层板 → 出 Gerber | 51 单片机小板、电源模块 | EDA 工具、封装、DRC、工艺规则 |
| L2 熟练 | 四层板、电源分割、差分对走线 | STM32 主控板、USB 设备 | 叠层设计、地平面、回流路径 |
| L3 高速 | 阻抗控制、等长、仿真验证 | DDR、千兆以太网、HDMI | 传输线理论、SI/PI、时序预算 |
| L4 专家 | 叠层/材料选型、电源完整性、EMC 整改 | 服务器主板、交换机、射频板 | 电磁场、材料学、仿真建模、量产工艺 |

<Callout type="warn" title="最容易走歪的路">
跳过 L1 直接啃 L3 的公式，是这一行最常见的时间浪费。**没有亲手做过一块能跑通的板，所有的“高速理论”都只是背下来的名词。**
</Callout>

## 二、零基础从何开始

不必等“学完了再来画板”，但下面几样东西缺了会寸步难行：

- **电路基础**：欧姆定律、KVL/KCL、RC/RL 充放电、戴维南等效。
  够用到能看懂分压、上拉电阻、去耦电容在干什么就行。
- **数字电路常识**：高低电平、上拉/下拉、开漏输出、三态、建立/保持时间的概念。
- **元器件识图**：电阻电容封装（0402/0603/0805/SOT-23/QFN/BGA）、极性、ESD 敏感件、
  datasheet 里哪些页真正重要（引脚定义、推荐焊盘、参考电路、封装尺寸）。
- **仪器实操**：万用表（通断、电压）、示波器（带宽、探头、地线弹簧）、可调电源（限流）。
- **焊接与返修**：热风枪、助焊剂、拆 QFN/BGA 的基本功。
  不会返修，就很难在调试中形成“设计 → 验证 → 修正”的闭环。

## 三、工具怎么选

<Callout type="info" title="本笔记的默认平台">
后续所有章节的操作步骤、界面说明与示例工程，**默认使用立创 EDA（嘉立创 EDA 专业版）**。
</Callout>

之所以选定它作为学习平台，主要是两点：

1. **对中文用户更友好**——全中文的界面、菜单与帮助文档，元件库、封装库、教程和社区问答也都以中文为主。
   初学阶段最大的阻力往往不是电路本身，而是被英文术语和陌生的操作路径卡住，这一点上它的优势很直接。
2. **有技术客服提供协助**——遇到封装缺失、设计规则报错、打样工艺疑问之类的问题，能获得人工答疑，
   而不是只能自己在论坛里翻帖子。对没有师傅带的初学者来说，这条反馈通道非常关键。

此外它还有两个附带好处：元件库与商城、打样服务打通，**从画完到下单打样是一条闭环**；
设计规则也默认贴合国内板厂的工艺能力，第一次出图不容易踩工艺坑。

| 工具 | 授权 | 适合谁 | 特点 |
| --- | --- | --- | --- |
| **立创 EDA**（默认） | 免费 | 学习与快速打样 | 全中文、有技术客服、元件库与打样打通 |
| **KiCad** | 开源免费 | 开源硬件、跨平台 | 全流程完整，社区库丰富，以英文生态为主 |
| **Altium Designer** | 商业 | 企业主流 | 规则系统与高速工具链成熟，行业招聘常见 |
| **Cadence Allegro / Xpedition** | 商业 | 高端高速与服务器 | SI/PI、约束管理最强，学习曲线最陡 |
| **LTspice / ngspice** | 免费 | 电路验证 | 做电源、滤波器、端接方案时先仿真再画板 |

<Callout type="idea" title="我的选择">
先**用立创 EDA 打通全流程**，把“原理图 → 布局 → 布线 → DRC → 出 Gerber → 打样 → 焊接调试”完整跑一遍；
等遇到工具能力的天花板（比如约束管理器、差分/等长自动化），再迁移到商业工具，那时学习成本会低很多。
</Callout>

## 四、完整设计流程

<Timeline>
  <TimelineItem marker="01" title="需求定义与规格拆解">
    明确这块板要做什么：功能框图、供电方案、接口类型、尺寸与安装约束、成本与工艺上限。
    **先把指标写成可验证的数字**（电压、电流、速率、温升），否则后面所有取舍都无从判断。
  </TimelineItem>

  <TimelineItem marker="02" title="原理图设计">
    按功能模块分块绘制，每个模块单独可测。注意上拉/下拉、去耦、参考电路照抄厂商建议值。
    这一步的产出是**电气正确性**，还谈不上“板子好不好做”。
  </TimelineItem>

  <TimelineItem marker="03" title="元件选型与封装库建立">
    确认封装与实物一一对应（引脚编号、极性、焊盘尺寸），优先用库中已验证的封装。
    新建封装时严格对照 datasheet 的推荐焊盘图，这是**最容易被忽略又最致命的一步**。
  </TimelineItem>

  <TimelineItem marker="04" title="叠层与布局规划">
    先定层数与叠层结构，再划分区域：电源、模拟、数字、高速接口各占哪块。
    按信号流向摆放器件，接口靠边、晶振靠芯片、大电流路径短而宽。
    **这一步决定后面 80% 的布线难度。**
  </TimelineItem>

  <TimelineItem marker="05" title="布线（电源 / 地 / 高速）">
    顺序建议：先电源与地，再关键高速信号，最后普通信号。
    高速信号优先保证回流路径完整，差分对等长等距，必要时才用自动布线收尾。
  </TimelineItem>

  <TimelineItem marker="06" title="DRC / DFM 检查">
    跑设计规则检查：线宽线距、过孔尺寸、焊盘间距、丝印压焊盘、板边留白。
    再按板厂的工艺能力表复核一遍最小线宽/最小孔径，改图永远比改板便宜。
  </TimelineItem>

  <TimelineItem marker="07" title="生产文件输出">
    导出 Gerber + 钻孔文件 + BOM + 贴片坐标，检查层数与钻孔文件是否对应，
    并**用 Gerber 查看器回看一遍**——只信预览，不信自己的记忆。
  </TimelineItem>

  <TimelineItem marker="08" title="打样、贴片与上电调试">
    上电前先测电源对地阻值、确认极性与脚位；上电时**用可调电源限流**，分模块逐级验证，
    定位问题后回改设计。
  </TimelineItem>

  <TimelineItem marker="09" title="改板迭代">
    把调试中暴露的问题（布局打架、散热不足、EMC 超标、可生产性差）回流到下一版设计，
    形成“设计 → 验证 → 修正”的闭环。第一版就完美的板子几乎不存在。
  </TimelineItem>
</Timeline>

<Callout type="warn" title="流程里最容易被忽略的两步">
一是**叠层与布局规划**（决定后面 80% 的布线难度），
二是**上电前的检查**（电源短路、极性反接、封装脚位错）。这两步省下的时间，调试时会加倍还回去。
</Callout>

## 六、必须建立的核心概念

### 1. 低速与高速的分界

分界并不在“频率高不高”，而在于 **信号上升时间与走线传播时延的关系**：

- 传播速度约为光速的 1/2（FR-4 中约 **6 in/ns ≈ 15 cm/ns**）。
- 工程经验：当 **走线长度 > 上升沿空间长度的 1/6** 时，就必须按传输线处理。
- 因此哪怕 10 MHz 的方波，只要边沿是 1 ns，几厘米的走线也已经“高速”了。

<Callout type="info" title="一句话理解">
高速不是“时钟快”，而是**边沿快**。低速思维看电压，高速思维看**电流的回路**。
</Callout>

### 2. 五个关键词

- **阻抗（Z₀）**：传输线特征阻抗，常见单端 50 Ω、差分 90 Ω（USB）/ 100 Ω（以太网、HDMI）。
- **参考平面与回流路径**：信号电流总要回到源端，**回流走哪条路，决定了这块板干不干净**。
- **反射与端接**：阻抗不连续 → 反射 → 过冲/振铃，靠串联/并联/戴维南端接收敛。
- **串扰**：相邻走线通过互容互感耦合，靠**间距（3W 原则）**、地线隔离、减小并行长度抑制。
- **时序与等长**：一组总线必须满足建立/保持窗口，等长是为了让到达时间一致。

### 3. 叠层与阻抗的直觉

| 结构 | 典型叠层 | 阻抗控制方式 | 适用 |
| --- | --- | --- | --- |
| 两层板 | 信号 / 信号 | 难控制（无完整参考面） | 低速、电源、极低成本 |
| 四层板 | 信号 / GND / PWR / 信号 | 微带线为主 | 绝大多数中低速产品 |
| 六层及以上 | 信号 / GND / 信号 / PWR / GND / 信号 | 微带 + 带状线 | DDR、千兆、射频、整机主板 |

<Callout type="idea" title="给 4 层板的建议">
优先使用 **SIG / GND / PWR / SIG** 结构：第二层完整地平面既做参考又做屏蔽，第三层电源平面为高速信号提供紧耦合的回流路径。**不要轻易打乱“一信号一参考”的配对关系。**
</Callout>

## 七、常见误区清单

- 一上来就追求“最专业的工具”，结果一周都在装软件、配库。
- 只用自动布线，不理解每条线为什么这样走。
- 忽略电源完整性：去耦电容随手摆、DC-DC 环路面积过大。
- 只看原理图正确，不管 **回流路径**，地平面被割得七零八落。
- 出图前不做 DRC/DFM 检查，打样回来发现线宽低于工艺下限。
- 不做叠层与阻抗规划就先布线，后期改板成本翻倍。
- 调试时直接上电、不限流、不逐级验证，一次烧掉整板。
- 抄参考设计时连“它为什么这样设计”一起抄，换一个器件就失效。

## 八、如何用好这份笔记

- **按章节顺序读**：前几章是后面所有内容的前提；跳读容易断链。
- **配套动手**：每读完一章，尽量在真实工程里找一个小场景验证一遍。
- **关注 Callout**：提示、警告、经验三类标注，通常对应最容易翻车的地方。
- **术语卡住就查附录**：高速领域大量结论来自英文资料与 datasheet，缩写不熟会严重拖慢阅读速度。
- **记录自己的坑**：这份笔记最大的价值不是“标准答案”，而是**自己踩过的坑和修正过程**。

## 九、常用术语与缩写（速查）

| 缩写 | 全称 | 含义 |
| --- | --- | --- |
| SI | Signal Integrity | 信号完整性：波形质量、反射、串扰、损耗 |
| PI | Power Integrity | 电源完整性：电源噪声、阻抗、去耦 |
| EMC / EMI | ElectroMagnetic Compatibility / Interference | 电磁兼容 / 电磁干扰 |
| ERC | Electrical Rule Check | 电气规则检查（在**原理图**阶段跑，别和 DRC 混） |
| DRC | Design Rule Check | 设计规则检查（间距、线宽、过孔等） |
| DFM | Design For Manufacturing | 可制造性设计 |
| TDR | Time Domain Reflectometry | 时域反射：定位阻抗不连续点 |
| Z₀ | Characteristic Impedance | 传输线特征阻抗 |
| ODB++ / Gerber | — | 生产输出格式 |
| BOM | Bill of Materials | 物料清单（含替代料） |
| PDN | Power Delivery Network | 电源分配网络 |
| FR-4 | Flame Retardant 4 | 最常用的板材，Dk ≈ 4.2–4.6 |
| Dk / Df | Dielectric Constant / Loss Tangent | 介电常数 / 损耗角正切，决定阻抗与损耗 |
