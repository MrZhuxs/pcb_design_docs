<DesignSop />

七步是顺序的：前一步的输出就是后一步的输入。**真正的分水岭在第 4 步之后**——前面错了只是改文件，后面错了要重新开料、重新打样。

## 一、EDA（Electronic Design Automation）

EDA 即电子设计自动化软件，是一种用于电子系统设计、仿真、分析、布局、布线、验证与制造准备的计算机程序集合。它包含一系列工具，让工程师与设计师能高效地创建复杂的电子系统和印刷电路板。

实际工作中，EDA 要干的活可以拆成四类：

| 环节 | 主要工具能力 | 产出 |
| --- | --- | --- |
| 原理图编辑 | 符号库、连线、网络标签、电气规则检查 | 原理图 + 网表 |
| 仿真与分析 | 直流/交流/瞬态仿真、信号与电源完整性 | 工作点、波形、余量 |
| 版图设计 | 布局、布线、叠层与阻抗、DRC/DFM | PCB 版图 |
| 制造准备 | Gerber、钻孔文件、BOM、贴片坐标 | 可直接下单的文件包 |

### 常见的 EDA 软件

- **Altium Designer**：企业里最常见的商用 EDA。收费软件，但相比其他付费授权，使用费相对低——年授权费用约 **5 万元**量级。规则系统、高速工具链、3D 与库管理都比较完整，招聘要求里出镜率最高。
- **嘉立创 EDA**：国产 EDA，免费使用，界面与操作符合国内使用习惯，上手快。内置丰富的原理图符号与封装库，并且**直接对接嘉立创商城**：画完就能查库存、下单打样、顺手把贴片一起做了，从设计到样机是一条通路。

<Callout type="idea" title="怎么选">
先用**嘉立创 EDA 把全流程跑通**（原理图 → 布局布线 → DRC → 出 Gerber → 打样 → 焊接调试），把"一块板从 0 到点亮"这件事完整经历一遍；
等遇到工具能力的天花板（约束管理、差分与等长自动化、SI 仿真），再迁到 Altium Designer，那时学习成本会低很多。
</Callout>

<Pitfall>不要用"哪个软件更专业"来决定起点。真正的门槛在电路与工艺，不在工具栏的位置。用免费工具做出能通过认证的板子，比用五万块的软件画一块点不亮的板强得多。</Pitfall>

## 二、原理图设计

原理图（Schematic）是**用标准符号和连线，描述电路里有哪些元件、它们之间如何电气相连**的图。它回答的是「谁和谁连在一起」，**不回答**「元件摆在哪儿、板子多大、线要多宽」——那些是 PCB 设计阶段的事。

同一个电气关系可以画成很多种样子：一条长线连过去，或者两头各放一个同名网络标签，在 EDA 里二者**完全等价**。所以原理图的好坏不看"画得像不像实物"，而看三件事：

1. **电气关系正确**：每个引脚都接对了，没有悬空、没有短路、没有漏掉上拉/去耦。
2. **可读**：信号从左到右、电源在上、地在下，功能分块清楚，别人（包括三个月后的自己）能看懂。
3. **可交接**：位号唯一、参数完整、符号与封装绑定正确——这三样直接决定后面的 BOM 与贴片。

<SchematicExcerpt />

<Callout type="info" title="原理图的真正产出是三样东西">
一是给人看的**图**（用于评审与存档）；二是给软件看的**网表**（决定 PCB 里哪些点必须连通）；三是给采购与贴片厂看的**BOM**（位号 + 型号 + 数量 + 封装）。原理图画错，后面每一步都在放大这个错误。
</Callout>

## 三、PCB 设计

PCB 设计本质上是**基于先前画好的原理图，创建 PCB 实体**的过程。它包含五个具体环节：

| 环节 | 要做的事 | 常见坑 |
| --- | --- | --- |
| 电子元件选择 | 按电气参数、封装可得性、成本、供货选型 | 选了封装冷门或停产的料，打样后买不到 |
| 板材形状定制 | 定板框尺寸、外形（矩形/异形）、安装孔与拼板 | 板框没留工艺边，贴片机夹不住 |
| 布局规划 | 按信号流与供电分区，接口靠边、晶振靠芯片、大电流路径短而宽 | 先布线后布局，越走越堵 |
| 布线设计 | 先电源与地，再关键高速，最后普通信号；保证回流路径完整 | 地平面被割碎、差分对不等长 |
| 丝印图案 | 位号、外框、极性、方向、板名与版本号 | 丝印压焊盘；极性标反，贴片全反 |

<Callout type="warn" title="布局决定一切">
布线难不难，八成在布局那一刻就定了。把"接口靠边、晶振靠近芯片、去耦电容贴着电源引脚、大电流回路尽可能小"这几条做到，剩下的布线是体力活；做不到，后面怎么调都是拆东墙补西墙。
</Callout>

## 四、检查与出图

这一步发生在下单之前，产物是**能直接交给板厂的文件包**：

- **DRC / DFM 检查**：线宽线距、孔径与孔环、焊盘间距、丝印压焊盘、板边留白，逐项过一遍。
- **按板厂工艺能力复核**：最小线宽、最小孔径、最小间距是否落在对方的能力表内。
- **出 Gerber + 钻孔文件 + BOM + 贴片坐标（Pick & Place）**。
- **用 Gerber 查看器回看一遍**：层数对不对、钻孔是否对齐、阻焊开窗有没有漏。**只信预览，不信记忆。**

<Pitfall>出图这一步最省时间也最省钱：在这里多花 20 分钟，能省掉一次 3–5 天的打样往返和一轮快递费。</Pitfall>

## 五、打样

产品正式大规模生产、推向市场之前，开发团队通常先做一轮**小批量样品生产**，这就是打样。它的目标很明确：

- 验证当前方案与设计**是否满足既定目标**；
- 是否达到既定的**功能与性能**指标；
- 是否还有**潜在问题**尚未发现。

所以打样的板子不是"越少越好"，而是**刚好够暴露问题**：关键模块各留一处测试点、关键网络留出飞线与探针位、多留两块备用板（焊接调试会消耗板子）。

## 六、SMT 贴片（可选）

打样时可以选择让板厂**代做元件安装与焊接**，也就是 SMT 贴片服务——这是**可选服务，需额外收费**，通常按点数/焊点数计价。

- **优点**：省掉手工焊接的时间与翻车风险，尤其是 0402、QFN、BGA 这类手工很难处理的封装；钢网、回流曲线都由工厂保证。
- **代价**：要额外付贴片费与钢网费；元件要么从板厂商城选，要么自己寄料（还要处理来料检验）；出了问题定位更麻烦——是设计问题、来料问题还是焊接问题，一时分不清。

<Callout type="idea" title="样板的建议做法">
第一版样板建议**先打裸板、自己焊一遍**：焊接过程本身就是一次设计审查（焊盘好不好上锡、间距够不够、丝印看不看得清）。
等设计基本稳定、要做 5–10 块的小批量时，再把 SMT 贴片一起下单，效率和一致性都会好很多。
</Callout>

## 七、功能验证

项目最后阶段，工程师必须验证电路板能正常工作：按模块通电、逐级测量、跑一遍功能测试，确认所有电路按预期工作。

建议按这个顺序做，出问题时才能定位到具体环节：

1. **不通电先测**：电源对地阻值、关键网络通断、极性元件方向。
2. **限流上电**：用可调电源限流到预期电流的 1.2–1.5 倍，先看静态电流是否异常。
3. **分模块验证**：电源 → 时钟 → 复位 → 通信 → 功能，一级一级点亮。
4. **边界条件**：高低温、电压拉偏、满负载、长时间老化。
5. **封闭测试**：选取一小组真实用户试用，收集实际使用中的反馈与性能数据，确认产品达到设计标准并满足用户需求。

<Pitfall>上电顺序错了会烧板：先插着所有负载、不限流、直接满电——这是样板阶段最常见的报废方式。限流电源不是可选项。</Pitfall>

## 八、一页 SOP 检查表

| 阶段 | 交付物 | 放行标准 |
| --- | --- | --- |
| 需求与规格 | 功能框图、指标表 | 电压/电流/尺寸/接口都写成可验证的数字 |
| 原理图 | 原理图、网表、BOM 初稿 | 电气规则检查通过，符号与封装一一绑定 |
| PCB 设计 | 版图 | 布局符合信号流，电源与地先走通，关键网络满足约束 |
| 检查与出图 | Gerber、钻孔、BOM、坐标 | DRC/DFM 全过，Gerber 回看无误，落在板厂能力内 |
| 打样 | 裸板 / 贴片板 | 数量够调试用，留足备用板与测试点 |
| 功能验证 | 测试记录、问题清单 | 全部指标达标，无未定位的异常 |

## 九、要点速记

```text
EDA：原理图 + 仿真 + 版图 + 制造准备四类工具
选型：企业常用 Altium Designer（年费约 5 万）；入门用嘉立创 EDA（免费、打通商城与打样）

原理图：说清"谁和谁相连"，不描述位置与尺寸
        产出 = 图（评审）+ 网表（决定连通）+ BOM（决定采购与贴片）
PCB 设计五件事：元件选型 / 板框外形 / 布局 / 布线 / 丝印

打样目标：验证方案、验证功能性能、暴露潜在问题
SMT 贴片：可选服务，额外收费；样板建议先裸板自己焊
功能验证：先测阻值 → 限流上电 → 分模块 → 边界条件 → 封闭测试

分水岭：出图之后每改一次都要花钱
```
