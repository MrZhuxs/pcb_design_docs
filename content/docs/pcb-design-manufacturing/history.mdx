印刷电路板（PCB）作为一件工业产品，历史不到一百年；但“电路”作为可以被计算、被书写、被制造的对象，已经有两百年。今天板上几乎每一条规则——线宽、间距、孔径、环宽、阻抗、叠层——都不是凭空规定的，而是某一段历史里被真实的失效与成本逼出来的。

下面按 **“连接方式”** 这条主线讲：导线 → 搭棚接线 → 单面板 → 双面板与金属化孔 → 多层板 → HDI 与封装级互连。读的时候不必记年份，重点记 **“为什么必须变”**：每一次跃迁的动因都是器件变小、变快、引脚变多。

## 一、三条主线与一个规律

同一段历史可以从三个角度读，它们互相咬合：

- **连接方式**：导线 → 搭棚 → 印刷导体 → 过孔 → 微孔。它决定板子长什么样。
- **器件形态**：电子管 → 通孔元件 → 贴片元件 → 球栅阵列 → 倒装裸片。它决定连接方式必须怎么改。
- **设计手段**：目视与手绘 → 贴带与照相 → CAD → 约束与仿真。它决定设计者要操心什么。

| 阶段 | 连接方式 | 代表器件 | 主要设计难点 | 关键工艺 |
| --- | --- | --- | --- | --- |
| 1900s–1940s | 导线、搭棚、端子板 | 电子管、继电器 | 接线正确、体积与重量 | 手工焊接、线束 |
| 1940s–1950s | 单面印刷电路 | 电子管、早期晶体管 | 布线密度、焊点可靠性 | 蚀刻、冲孔、浸焊 |
| 1960s–1970s | 双面板 + 金属化孔 | DIP 封装 IC | 双面协调、过孔规划 | 沉铜电镀、多层压合 |
| 1980s–1990s | 多层板 + 贴片 | SMD、QFP、BGA | 阻抗、EMC、可制造性 | 波峰/回流焊、激光钻孔 |
| 2000s–今 | 任意层 HDI、封装级互连 | BGA/CSP、倒装、Chiplet | 损耗、电源完整性、时序 | 半加成、2.5D/3D 封装 |

<KeyBox title="一个贯穿两百年的规律">
每一次形态跃迁，都由**器件变小、变快、引脚变多**驱动；而设计难点随之迁移：
**“能不能连上” → “电气上准不准” → “制造上良率够不够”。**
今天这三件事同时压在同一块板上，这正是高速 PCB 设计难的地方。
</KeyBox>

## 二、史前：电路先变成“可计算的东西”（1800–1890s）

在印刷电路出现之前，先出现的是**关于电路的知识**。这一百年里留下的定律，至今仍然是 EDA 软件在后台求解的东西，也是板厂每一道工序的物理依据。

| 年份 | 事件 | 与 PCB 的关系 |
| --- | --- | --- |
| 1800 | 伏打电堆 | 第一个可持续供电的直流电源，电路实验从此有了“电池”这个前提 |
| 1820 | 奥斯特发现电流的磁效应 | 电流与磁场绑定，一百多年后成了串扰、环路电感的源头 |
| 1826–1827 | 欧姆定律发表 | 第一次把“电压、电流、电阻”写成可计算的关系 |
| 1831 | 法拉第电磁感应 | 变压器、开关电源、一切 di/dt 问题的起点 |
| 1833 | 法拉第电解定律 | **电镀的定量基础**，后来正是它支撑了金属化孔工艺 |
| 1845 | 基尔霍夫定律（KCL / KVL） | 今天的网表求解、连通性检查，都建立在这两个守恒上 |
| 1859 | 普兰特铅酸电池 | 可充电储能，让移动式电气设备成为可能 |
| 1865 | 麦克斯韦方程组 | 电场与磁场的统一；一个世纪后才被工程化为“传输线与特征阻抗” |
| 1876 | 贝尔电话 | 第一个对信号质量（而不只是通断）提出要求的大规模电气系统 |
| 1879 | 爱迪生碳丝白炽灯 | 电气产品进入家庭 |
| 1882 | 纽约珍珠街发电站（直流） | 电网出现，供电从“实验室”变成“基础设施” |
| 1888–1891 | 特斯拉交流感应电机；劳芬—法兰克福 175 km 三相输电 | 交流在远距离输电上胜出，电机与电网的形态由此定下来 |
| 1895 | 尼亚加拉瀑布水电站投运 | 大型交流发电与输电工程定型 |

<Callout type="info" title="这个时代还没有“电子产品”">
此时的电路是机器与基础设施：裸铜线、瓷瓶、端子排、木质或铸铁底盘，靠电工手艺现场配线。
“可复制、可批量、可检验”这三件事，要等到电子管把电路压缩进一个机箱之后才成为硬需求。
</Callout>

## 三、电子管时代：搭棚接线的极限（1904–1940s）

1904 年弗莱明的真空二极管、1906 年德福雷斯特的三极管（Audion）让“放大”成为可能，收音机、电话中继、雷达与通信设备随之出现。但装配方式仍然是**把元件固定在金属底盘上，再用导线一根根飞过去**——也就是点对点接线（point-to-point）与搭棚。

痛点非常具体：

- **不可复制**：同一型号两台设备，内部接线可以完全不同，调试依赖老师傅的经验。
- **错误率高**：焊点数量随元件数量快速增长，虚焊、短路只能靠肉眼与万用表找。
- **体积与重量**：线束本身占据大量空间，对机载、弹载设备是致命的。
- **维修困难**：没有“图纸与实物一一对应”的载体，只能顺着线摸。

战争与广播把“一致性”和“体积”变成了硬指标，于是“把连线印在板子上”的想法被反复提出——但大部分方案在产业上失败了。

| 年份 | 人物 / 方案 | 做法 | 结局 |
| --- | --- | --- | --- |
| 1903 | Albert Hanson（德国） | 在绝缘板上层压扁平金属箔，可多层叠放 | 有专利，无产业 |
| 1904 | 托马斯·爱迪生 | 尝试用化学镀的方法把导体“印”到亚麻纸上 | 实验性质，未量产 |
| 1913 | Arthur Berry（英国） | 提出“印刷 + 蚀刻”的图形化方法 | 思路正确，工艺超前 |
| 1910s–20s | Max Schoop（美国） | 通过掩模把熔融金属火焰喷涂到板上 | 精度与附着力不足 |
| 1925 | Charles Ducas（美国） | 用模板在绝缘体上电镀出导体图案 | 精度受限于模板 |
| 1936–1947 | John Sargrove（英国） | ECME：在胶木板上喷涂金属形成电路，号称每分钟 3 块收音机板 | 工艺过于激进，随器件换代而废弃 |

<Pitfall>这些早期方案失败的共同原因不是“想法不对”，而是**当时没有适配的器件**：电子管又大又热、引线又长，印刷板省下的那点连线空间毫无意义。工艺从来不是单独成功的，它必须和器件形态一起换代。</Pitfall>

## 四、1936：Eisler 与“减成法”的诞生

1936 年前后，奥地利工程师 **Paul Eisler** 在伦敦研制收音机时，做出了真正意义上的现代印刷电路板：把整块铜箔覆在绝缘基材上，再用蚀刻把不需要的部分去掉，留下的铜就是导线。

这个“先把整面铺满、再减掉多余”的思路，就是今天板厂的主力工艺——**减成法（subtractive process）**，与今天的工艺几乎同源。之后的关键节点：

- **1941 年**：史料记载德国磁性感应水雷引信中使用过多层印刷电路。
- **1943–1944 年**：美国把印刷电路大规模用于近炸引信（VT 引信），产量接近一千万只，每只含约 130 个微型元件。这是印刷电路**第一次通过大批量生产的验证**。
- **1948 年**：相关技术解密并转向民用。

<Callout type="idea" title="为什么是引信">
近炸引信的需求画像几乎是给印刷电路量身定做的：**一次性使用、极大批量、对一致性要求极高、体积重量必须极小**。
这四条正好命中点对点接线的全部弱点，也解释了为什么一项 1936 年的发明要等到 1943 年才落地。
</Callout>

## 五、1950s：Auto-Sembly 与双面板

战后最关键的一步不是新发明，而是**把做法写成规范**。

- **1949 年**，美国陆军通信兵团的 Moe Abramson 与 Stanislaus F. Danko 开发出 **Auto-Sembly** 工艺；**1951 年**在《Electronics》杂志公开。它的价值在于把“冲孔定位 → 插入元件 → 浸焊”变成一套可复制的流程，成为印刷电路的第一套事实标准。
- **1954 年**，Regency TR-1 晶体管收音机上市，消费电子开始批量使用印刷板；印刷电路从军品走向日用品。
- **1950 年代中后期**，**金属化孔（PTH，Plated Through Hole）**工艺成熟：孔壁被镀上铜，上下两面的导线第一次可以“穿过板子”而不是“绕开板子”。

PTH 的意义常被低估。它让双面板布线从奢侈变成常规，也让**孔第一次成为设计对象**——孔径、焊盘环宽、金属化质量、孔到线的连接方式，从此都要在图纸上交代清楚。板厂的工艺链也在这一时期定型：

## 六、集成电路：板级互连被“降级”又“升级”（1958–1970s）

- **1958 年**，杰克·基尔比在德州仪器做出第一块集成电路（锗）；**1959 年**，罗伯特·诺伊斯在仙童用平面工艺与铝互连做出可量产的硅集成电路，让“批量制造”成为可能。
- 集成电路把大量原本在板上的连线收进了晶圆，PCB 的职责被压缩成三件事：**把封装引脚连起来、把电送进去、把热排出来**。
- 但引脚数在持续上升（DIP 从 14/16 脚走到 40/64 脚），加上**多层板**在大型机与军用电子中普及，板级密度压力反而更大。
- **1965 年**摩尔定律提出；**1971 年** Intel 4004 问世，微处理器把引脚与总线密度再推一个台阶。
- 装配端出现自动插件机与波峰焊（1950 年代末出现、1960 年代普及）——板子从此必须是“给机器做的”，“可制造性”开始有独立价值。

设计手段在这一阶段仍然是手艺活：**红蓝胶带贴在聚酯薄膜上，按 2:1 或 4:1 放大绘制，再照相缩小制版**。1960 年代矢量光绘机（photoplotter）出现后，Gerber 格式逐步取代胶带，成为设计数据与制造设备之间的交换标准——这个“数据接口”一直用到今天。

<Callout type="warn" title="多层板的门槛不在层数">
多层板真正的门槛是**压合与对准**：层与层之间的图形要同心，否则过孔打下去接不上。所以“层数”只是工艺能力的标签，而“对位精度”才是它的实质。
</Callout>

## 七、SMT 与 HDI：从“孔”到“盘”，再到“微孔”（1980s–2000s）

贴片（SMT）是板级互连的第二次跃迁：元件从“穿过板子”变成“贴在板面上”，焊盘取代孔成为主角。1980 年代片式阻容与 SOP/QFP/PLCC 大量普及，板面利用率与布线密度显著提高；代价是焊点从“看得见的穿孔”变成“看不见的贴片”，回流焊曲线、热应力、立碑与虚焊成为新的失效主因。

随后是密度链条上更陡的一段：

- **1980 年代末，BGA（球栅阵列）**把引脚以阵列形式铺在封装底面，引脚数暴涨；代价是走线必须“钻到内层去”，**盲孔、埋孔**成为必需。
- **HDI（高密度互连）**：1984 年惠普 Finstrate 用激光钻孔做出最早量产的积层板；**1991 年** IBM 日本推出 SLC（Surface Laminar Circuit），瑞士 Dyconex 推出 DYCOstrate，微孔（microvia）工艺此后成为主流，并进一步发展为**任意层互连（any-layer）**。
- **2006 年 7 月**欧盟 RoHS 生效，无铅化（SAC 合金、更高的回流温度）连带改变了板材的 Tg/Td 要求、表面处理（ENIG / OSP / 沉锡）与整条工艺窗口。

从此，“过孔”从工艺细节升级为设计核心：孔径、孔环、孔到盘间距、过孔残桩（stub）、背钻深度，都会直接写进约束表。

## 八、工具：从贴带到约束驱动

| 年代 | 手段 | 输出 | 局限 |
| --- | --- | --- | --- |
| 1950s–60s | 手工贴带 + 刻膜，2:1 或 4:1 放大绘制 | 照相底片、手工钻孔图 | 双面板靠人眼对齐，改一次等于重画 |
| 1970s | CAD 与矢量光绘机 | Gerber 数据 | 本质仍是“画线工具”，无规则检查 |
| 1980s | PC 端 EDA 兴起（Protel 1985、Eagle 1988、Mentor BoardStation、Cadence Allegro 1988 等） | 网表 + 版图 + 自动布线 | 自动布线不理解回流与阻抗 |
| 1990s | 约束管理、DRC/DFM 自动化、SI 仿真接入流程；KiCad 1992 开源 | 带规则的版图与仿真报告 | 建立约束本身需要判断力 |
| 2010s– | 国产一体化平台（如立创 EDA）打通元件库、封装库与打样 | 一键出图、一键下单 | 工具再强也不能替代对电磁与工艺的理解 |

<KeyBox title="工具史的主线">
不是“画得更快”，而是**把经验变成可执行的检查**。
线宽下限、孔环、间距、阻抗、等长——每一条规则背后都曾是一次真实的报废；工具的价值就是让这些教训不必由下一个人重新踩一遍。
</KeyBox>

## 九、高速时代：PCB 变成“电磁器件”（1990s–今）

器件变快的直接后果是：**板子不再只是“连着的东西”，而成了电路的一部分**。分界不在时钟频率，而在边沿速率——当走线长度超过上升沿空间长度的约 1/6 时，就必须按传输线处理（FR-4 中传播速度约 6 in/ns ≈ 15 cm/ns）。于是 10 MHz 的方波，配上 1 ns 的边沿，几厘米的走线就已经“高速”了。

| 时间 | 接口 / 技术 | 单通道速率 | 对板子的新要求 |
| --- | --- | --- | --- |
| 1992 | PCI（32 bit / 33 MHz） | 并行总线 | 等长、负载效应 |
| 2003 | PCIe 1.0 | 2.5 GT/s | 差分对、参考平面 |
| 2010 | PCIe 3.0 | 8 GT/s | 损耗预算、过孔 stub |
| 2017 | PCIe 4.0 | 16 GT/s | 低损耗板材、连接器与 cable |
| 2019 | PCIe 5.0 | 32 GT/s | 玻纤效应、背钻、仿真前置 |
| 2022 | PCIe 6.0 | 64 GT/s（PAM4） | 通道建模、均衡与误码率 |

同时，**封装与板的边界正在消失**：2.5D 中介层（interposer）、EMIB、Chiplet 与 UCIe（2022）、以及玻璃基板路线（Intel 2023 公布），把一部分“板级互连”搬到了封装内部甚至晶圆级。对硬件工程师的含义很直接：**板级设计与封装设计必须一起看**，天真的“只管把线连到封装球上”已经不够了。
