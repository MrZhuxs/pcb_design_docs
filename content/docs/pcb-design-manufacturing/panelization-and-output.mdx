前面几章都在讲「怎么画对」。这一章讲**怎么把它变成一块真板子**。

设计画完的那一刻，还有三件事要过：

1. **拼板**——单块小板没法在 SMT 线上跑，要拼成一整张生产板；
2. **出图**——把设计翻译成板厂能读的格式（Gerber 等），一个层都不能漏；
3. **过检**——DRC/DFM 自查，然后接受板厂的工艺下限约束。

再加上「标准」这条线索：为什么板厂会问你「要过 IPC-2 级还是 3 级」，为什么叠层表上要写 IPC-4101 的板材型号。

---

## 一、为什么要把小板拼成大板

一块 20×20 mm 的板，直接上 SMT 线会遇到三个麻烦：

| 麻烦 | 后果 |
|---|---|
| 太小，卡在传送轨道上 | 传不过去，或者掉进机器里 |
| 印刷与贴片抓不稳 | 定位偏差、锡膏偏移 |
| 每次只做一块 | 设备利用率极低，成本摊不下来 |

所以把多块小板拼成一张「**生产板（Panel）**」，跑完整条线之后再分板。

这笔账很清楚：**拼板省的是生产效率，花的是板面积**——工艺边、间距、Mark 点全都要从板子上扣出来。

## 二、两种分板方式

<VcutVsMousebite />

| 方式 | 做法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **V-CUT（V 割）** | 用 V 形铣刀沿**直线**在正反两面各切一刀，切深约板厚 **1/3**，留中间连接筋 | 成本低、效率高、分板后**板边整齐无毛刺**、可手工掰断 | **只能走直线**，做不了异形板；元件需距 V-CUT 线 **≥5 mm** | 外形规则的矩形板 |
| **邮票孔（Mouse Bite）** | 沿板边铣槽，槽边留一排小孔（孔径 **0.5～0.8 mm**、孔距 **0.8～1.2 mm**），像邮票齿 | 可做**任意形状**、分板应力小、连接可靠 | 成本较高、分板后有**毛刺**需修整、占板边空间 | 异形板、圆板、板边有元件的板 |

**记忆口诀：V-CUT 走直线、便宜、整齐；邮票孔任意形、贵、有毛刺。**

<Callout type="warn" title="两条最容易踩的坑">
① **元件不能靠近 V-CUT 线**（≥5 mm）。掰板是一个「弯折」动作，靠近切口的焊点会被直接扯裂——这是新手最常犯的机械失效。
② **V-CUT 切深不是越深越好**。切到板厚的 1/3 左右刚好，太浅掰不断，太深连接筋太薄，运输途中自己就断了。
</Callout>

## 三、拼板的四类配套要素

<PanelLayout />

### 1. 工艺边（Rail / Breakaway）

在板边加宽 **≥5 mm** 的辅助边，给 SMT 设备的传送轨道与夹爪用，分板后整条去掉。

<Mark>工艺边上不许放任何需要保留的东西</Mark>——它最后会被整条撕掉。

### 2. Mark 点（基准点 / Fiducial）

贴片机的相机靠它做光学定位。参数很固定，几乎是行业惯例：

| 项目 | 要求 |
|---|---|
| 铜盘直径 | **⌀1 mm**（裸铜，不盖阻焊） |
| 阻焊开窗 | **⌀2 mm**（比铜盘大一圈） |
| 净空区 | 周围 **3 mm** 内无其他铜、无丝印 |
| 数量 | **至少 3 个**，板角对角线布置；拼板时「全局 Mark + 每块小板 Mark」 |

为什么开窗要比铜盘大：贴片机识别的是「铜与阻焊的反差」。开窗大一圈，才能保证铜盘边缘不被阻焊搭住；周围 3 mm 净空是为了让算法能干净地找到它的重心。

### 3. 定位孔（Tooling Hole）

测试架、工装、模具的定位用。孔径 **2.0～3.0 mm**，**非金属化**（不镀铜），一般放在工艺边上。

### 4. 板间距与方向

- 小板之间留 **1.6～3.0 mm** 间隙（V-CUT 取小值，邮票孔取大值）；
- 同一拼板内所有小板**方向一致**：一次过炉、一次印刷，炉温曲线与钢网开孔才能统一。

> **判断题要点**：「V-CUT 是 PCB 拼板时常用的分板方式」——**正确**。

## 四、出图：给板厂的文件

### 常用格式

| 格式 | 说明 |
|---|---|
| **Gerber（RS-274X）** | **最通用的光绘文件格式**。逐层输出线路、阻焊、丝印等，几乎被所有板厂接受 |
| **ODB++** | 把叠层、钻孔、网络、BOM 打包在一个文件里的**完整制造数据**，信息全、不易出错 |
| **IPC-2581** | 开放标准的制造数据格式，ODB++ 的开放替代方案 |
| **Excellon** | **钻孔文件**格式（记录孔径与坐标） |
| **DXF / DWG** | 板框、结构图（机械层） |
| **PDF** | 装配图、丝印图，**仅供人工参考，不能用于生产** |

> **填空题要点**：PCB 设计文件常用格式为 **Gerber 和 ODB++**。

<Callout type="idea" title="一定要做「Gerber 回看」">
导出 Gerber 之后，用**独立的 Gerber 查看器**把每一层重新打开看一遍。因为你在 EDA 里看到的「漂亮的板」，和板厂拿到的 Gerber 可能不是一回事：丝印压焊盘、阻焊没开窗、某一层根本没导出来（比如机械层忘勾选）、钻孔文件孔径表缺失——这些问题在 EDA 里看不出来，在 Gerber 里一眼就能看见。
</Callout>

### 设计流程的固定顺序

**原理图设计 → 元件库/封装库准备 → 导入网表 → 板框与叠层设置 → 布局 → 布线 → 覆铜 → DRC 检查 → 输出制造文件（Gerber / ODB++ / 钻孔 / BOM / 坐标）**

这个顺序不是建议，是依赖关系：没有网表就没法布局，没有叠层就算不出阻抗，没 DRC 就不知道能不能做。

## 五、IPC 标准族：板厂的「通用语言」

**IPC = Institute for Printed Circuits**，PCB 行业最有影响力的标准制定组织。

| 标准号 | 内容 | 用途 |
|---|---|---|
| **IPC-2221** | **印制板设计通用标准** | **最核心的设计标准**：线宽、间距、孔径、载流、爬电距离 |
| IPC-2222 | 刚性有机板分标准 | 2221 的补充 |
| IPC-2223 | 挠性板设计标准 | FPC 设计 |
| IPC-6012 | 刚性板**质量与性能**要求 | 制造质量 |
| IPC-A-600 | 印制板**验收**标准 | 外观允收（板厂给你的判定依据） |
| IPC-A-610 | 电子**组装**验收标准 | 焊点允收（SMT 厂的判定依据） |
| IPC-7351 | **贴片焊盘图形**标准 | Land Pattern 尺寸 |
| IPC-2152 | **载流能力**计算标准 | 替代老的 2221 图表 |
| IPC-2581 | 制造数据格式 | 数据交换 |
| IPC-4101 | 基材（覆铜板）规范 | 板材选型 |

> **填空题要点**：IPC 标准中，通用印制板设计规范的标准号是 **IPC-2221**。

<Callout type="info" title="这几个号的记忆方式">
**2xxx 系列是「设计」**（2221 通用、2222 刚性、2223 柔性）——你画图时遵守的。
**6xxx 系列是「性能与质量」**（6012 刚性板）——板厂制造时遵守的。
**A-xxx 是「验收」**（A-600 板、A-610 组装）——验货时遵守的。
**7351 与 2152 是「算数」**（焊盘尺寸、载流）——落在具体数字上。
</Callout>

其他常见规范：**国标 GB/T 4588 系列**、**UL 94**（阻燃等级）、**RoHS**（有害物质限制）、**REACH**。

## 六、DRC 与 ERC：一个查版图，一个查原理图

| 缩写 | 全称 | 检查对象 | 查什么 |
|---|---|---|---|
| **DRC** | **D**esign **R**ule **C**heck（设计规则检查） | **PCB 版图** | 线宽线距、孔径环宽、阻焊、平面间距 |
| **ERC** | **E**lectrical **R**ule **C**heck（电气规则检查） | **原理图** | 输出对输出、无驱动、电源短路、悬空输入 |

> **单选题陷阱**：DRC 是**设计规则检查**，不是「电气规则检查」。ERC 才是电气规则检查，而且它在**原理图**阶段跑。

### 常见 DRC 规则六类

| 类别 | 典型规则 |
|---|---|
| 线宽 / 线距 | 最小线宽、最小线距 |
| 间距类 | 走线到焊盘、焊盘到焊盘、铜皮到板边、丝印到焊盘 |
| 孔径类 | 最小孔径、最小环宽、孔到孔间距 |
| 阻焊 | 阻焊桥宽度、开窗间距 |
| 平面 | 平面间距（Anti-pad）、铺铜连接方式 |
| 其他 | 短路 / 开路、重复网络、未布线、器件重叠 |

## 七、DFM：先问板厂能做到哪一步

**DFM（Design for Manufacturability，可制造性设计）**：设计阶段就考虑板厂的工艺能力与成本，避免「设计出来做不出来」。

### 板厂工艺能力（示例，下单前必须按具体厂家核对）

| 项目 | 常规能力 | 高精度能力 |
|---|---|---|
| 最小线宽 / 线距 | **6/6 mil（0.15 mm）** | 4/4 mil（0.1 mm）、3/3 mil |
| 最小机械钻孔 | 0.3 mm | 0.2 mm |
| 最小激光盲孔 | — | 0.1 mm |
| 板厚 / 孔径比 | 8:1 | 12:1 |
| 最小环宽 | 0.15 mm | 0.13 mm |
| 阻焊桥 | 0.15 mm | 0.1 mm |
| 板厚公差 | ±10% | ±10% |
| 阻抗控制 | **±10%** | ±5% |
| 最小字符线宽 / 字高 | 0.15 / 0.8 mm | 0.13 / 0.6 mm |

这张表的作用是：**画图的时候就知道哪些数字是「不可能」的**。比如想要 3/3 mil 的线，就要接受价格翻几倍、且只有少数厂能做。

### DFM 常查的九项

1. 线宽线距是否达工艺下限；
2. 焊盘是否够大；
3. 阻焊桥是否够宽；
4. 丝印是否压焊盘；
5. 孔是否太靠板边；
6. Mark 点是否规范；
7. 板边元件是否影响分板；
8. 是否有**孤岛铜（死铜）**——需要加泪滴或连接；
9. 拼板与工艺边是否够宽。

## 八、常见缺陷与检验手段

| 缺陷 | 原因 | 影响 |
|---|---|---|
| **开路（Open）** | 蚀刻过度、断线、孔无铜、划伤 | 电路不通，功能失效 |
| **短路（Short）** | 蚀刻不足残铜、锡桥、异物 | 电源短路、烧器件 |
| **孔无铜 / 孔壁分离** | 除胶渣不良、活化不足、电镀异常 | 层间不导通，可靠性差 |
| **侧蚀过大 / 线宽不足** | 蚀刻液过强、时间过长 | 阻抗偏移、载流不足 |
| **阻焊偏位 / 阻焊桥断裂** | 对位偏差、开窗过小 | 露铜、焊接桥连 |
| **丝印压焊盘 / 字符模糊** | 设计失误、油墨或网版问题 | 可焊性差、虚焊 |
| **翘曲（Warpage）** | 叠层不对称、层压应力 | 贴片不良、装配困难 |
| **分层 / 起泡** | 棕化不良、除胶渣不足、受潮 | 可靠性失效 |
| **金面发黑（Black Pad）** | 沉金工艺中镍层过度腐蚀 | 焊接不良、掉件 |
| **板边毛刺** | 铣边 / 分板工艺 | 划伤、装配问题 |
| **阻抗超差** | 线宽 / 介质厚度偏差 | 高速信号反射 |

### 检验手段与它们各自能看见什么

| 手段 | 能查什么 |
|---|---|
| **目视 / AOI** | 外观、图形缺陷（开路短路、缺口、残铜） |
| **飞针测试 / 测试架** | 开短路**电测**（通断） |
| **X-Ray** | BGA 焊点、层间对位、孔铜厚度 |
| **TDR（时域反射计）** | **阻抗**是否达标 |
| **切片分析（Cross Section）** | 孔铜厚度、层间结合、介质厚度 |
| **可焊性 / 离子污染 / 热冲击** | 工艺洁净度与长期可靠性 |

<Callout type="idea" title="把「检验手段」和「缺陷」配对记">
最有价值的一列不是缺陷名称，而是「**这个缺陷靠什么手段才能发现**」。
开路短路 → 电测（飞针）；外观缺陷 → AOI；内部孔铜 → 切片与 X-Ray；阻抗 → TDR；可焊性 → 可焊性测试。**看不到的缺陷才是真正贵的缺陷**。
</Callout>

## 九、四个顺手的技巧

| 技巧 | 做法 | 解决什么 |
|---|---|---|
| **泪滴（Teardrop）** | 走线与焊盘连接处加圆滑过渡 | 防钻孔偏位断线，顺带减小阻抗突变 |
| **覆铜（Copper Pour）** | 大面积接地铜皮，**实心或网格 + 足够缝合过孔** | 提供回流与屏蔽；注意别留**孤岛铜/天线铜** |
| **包地（Guard Ring）** | 用接地铜皮把敏感信号围起来并打过孔 | 抑制串扰与辐射（包地本身必须多点接地才有效） |
| **缝合过孔（Stitching Via）** | 沿板边与平面分割处密集打孔 | 保证平面等电位，抑制边缘辐射 |

## 十、本章相关的易错点辨析

| 易错说法 | 正确理解 |
|---|---|
| 「印刷电路板」 | 规范术语是「**印制**电路板」，强调图形**转移**工艺 |
| V-CUT 元件可以贴着切口放 | 不行，元件要离 V-CUT 线 **≥5 mm** |
| Mark 点随便画个焊盘就行 | 必须 ⌀1 mm 裸铜 + ⌀2 mm 开窗 + 周边 3 mm 净空，**≥3 个** |
| DRC = 电气规则检查 | **错**。DRC = 设计规则检查；ERC = 电气规则检查，在原理图阶段 |
| 邮票孔比 V-CUT 便宜 | 反了。邮票孔更贵，因为它要铣槽、分板后还要修毛刺 |
| PDF 可以直接发板厂生产 | 不能。生产要 Gerber/ODB++，PDF 只供人看 |
