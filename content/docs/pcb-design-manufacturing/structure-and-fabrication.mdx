《PCB 与电路发展史》讲的是“连线”这件事怎么演化。现在把一块板拿到台面上拆开：**双面板由哪五个要素构成**、**从覆铜板到成品要经过哪些工序**、**层数增加后结构怎么变**、**孔为什么分三种**。

如果你手上只有一块打样回来的板，也可以对照着看：把它沿厚度方向“拆开”，能拆出来的东西基本就是下面这五层——截面里它们贴在一起，分层的图里才看得清各自的形状。

## 一、双面板的五个要素

| 要素 | 材料 | 作用 | 常见参数 |
| --- | --- | --- | --- |
| 介质层（基材） | 玻璃纤维布 + 环氧树脂（FR-4） | 隔开顶层与底层的铜，同时提供机械支撑 | 板厚 0.8 / 1.0 / 1.6 mm，Tg 130–180 °C |
| 线路（铜箔） | 覆铜板上的铜层 | 元件之间的导电通路 | 1 oz ≈ 35 µm 厚；线宽/间距常见 4/4 mil 起 |
| 通孔 | 孔壁镀铜（PTH） | 让顶层与底层的导线彼此导通 | 孔径 0.2–0.3 mm；纵横比通常不超过 8:1 |
| 阻焊层（防焊油墨） | 环氧类树脂，绿 / 黑 / 蓝 / 白等 | 不该上锡的地方挡住焊料，兼防氧化与桥连 | 颜色不影响电气性能 |
| 丝印 | 白色（或彩色）油墨 | 标注位号、元件外框、方向与极性 | 不允许压在焊盘上 |

### 1. 介质层

绝缘材质，多以玻璃纤维为主——准确地说是**玻璃纤维布浸渍环氧树脂后固化**，板厂叫 FR-4。它的作用有两个：把顶层与底层的电路隔开，以及把整块板撑起来。板越薄、层数越多，介质层就越薄，**阻抗与串扰的问题也就越早出现**。

### 2. 通孔

贯通孔（PTH）把上下两层的导线连通。没有它，双面板只能算“两张单面板背靠背”。孔壁靠化学沉铜再电镀加厚，所以孔金属化的质量直接决定可靠性——孔壁太薄，热循环几次就可能开裂。

### 3. 阻焊层（防焊油墨）

整块板上并非所有铜面都要覆盖焊锡。**不该上锡的区域涂上阻焊油墨**（通常是环氧树脂体系），既挡住焊料、防止相邻焊盘桥连，也把铜与空气隔开、减缓氧化。板厂常说的“绿油”，就是最常见的一种。

<Callout type="warn" title="颜色只是颜色">
绿、黑、蓝、白、红、哑黑……阻焊颜色**不改变电气性能**，只影响观感、字符对比度和某些工艺良率（比如白色阻焊对曝光能量更敏感）。选颜色时不必考虑“性能差异”，但要知道颜色越深越难看清走线，调试时会吃亏。
</Callout>

### 4. 丝印

丝印的主要功能是在板上标注**零件名称、位置框、方向与极性**，供后续组装、维护和辨识使用。它是给人和机器看的“注释层”，没有任何电气作用。

<Pitfall>丝印压在焊盘上，会让焊料润湿不良、元件立碑或虚焊。出图前一定要检查“丝印压焊盘”这一项 DRC——这是最典型的低级错误之一。</Pitfall>

### 5. 线路（铜箔）

基材上的铜面经过**曝光与化学蚀刻**，去掉多余的部分，留下设计好的路径，把元件之间的连接真正实现出来。它的宽度决定载流与温升，它的间距决定能不能做出来——这两件事分别对应设计规则里的线宽与线距。

## 二、原料：覆铜板（CCL）

PCB 通常由**覆铜板**加工而来。覆铜板也称**铜箔层压板**，是由一层或多层铜箔粘在一整块绝缘基材上组成的板子——板厂下单时问你的“板材、铜厚、板厚”，问的就是它。

<CopperCladLaminate />

铜箔厚度用“oz”表示，指的是**一平方英尺面积上的铜重一盎司**对应的厚度：1 oz ≈ 35 µm。载流大的板（电源、电机驱动）会选 2 oz 甚至更厚。

板材家族大致是这样分的：

| 板材 | 组成 | 特点 | 典型用途 |
| --- | --- | --- | --- |
| FR-4 | 玻纤布 + 环氧树脂 | 通用、便宜、Dk ≈ 4.2–4.6 | 绝大多数数字与消费类产品 |
| CEM-1 / CEM-3 | 纸基或复合基 + 环氧 | 成本更低，机械与耐热略逊 | 单面板、低成本家电 |
| 高频板材（如 PTFE 系） | 聚四氟乙烯或改性树脂 | Dk 稳定、Df 低，损耗小 | 射频、毫米波、高速背板 |
| 铝基板 | 铝基 + 绝缘层 + 铜 | 导热好，单面为主 | LED、电源、功率模块 |
| 柔性 PI（FPC） | 聚酰亚胺 | 可弯折、可做动态弯折 | 摄像头模组、连接排线 |

<Callout type="info" title="下单时要说清的四件事">
板材类型、板厚、铜厚、表面处理。这四项不写清楚，板厂会按默认值生产，而默认值未必满足你的载流、阻抗或散热需求。
</Callout>

## 三、从设计到成品：九步工艺

| 步骤 | 目的 | 关键控制点 |
| --- | --- | --- |
| 1. 设计 | EDA 里完成原理图、PCB 版图与 BOM | 网表一致、封装正确、DRC/DFM 通过 |
| 2. 开料 | 把大张覆铜板裁成生产拼板尺寸 | 板材型号、板厚、铜厚、烤板去应力 |
| 3. 钻孔 | 按设计在对应位置钻出过孔与插件孔 | 孔径、孔位精度、孔壁粗糙度 |
| 4. 金属化孔 | 沉铜 + 电镀，让孔壁导电（PTH） | 孔铜厚度、背光等级、深镀能力 |
| 5. 图形转移 | 用抗蚀材料盖住要保留的铜（丝印抗蚀油墨或贴干膜 → 曝光 → 显影） | 对位精度、曝光能量、显影干净 |
| 6. 蚀刻 | 化学药水溶掉没有抗蚀层保护的铜，留下设计路径 | 侧蚀、线宽均匀性、蚀刻液浓度 |
| 7. 阻焊 | 涂阻焊油墨并开窗，让焊盘露出来 | 开窗偏移、油墨厚度、固化度 |
| 8. 丝印 | 印上位号、外框、极性与方向 | 不允许压焊盘、字符清晰度 |
| 9. 表面处理 | 保护裸露铜面，保证可焊性与接触可靠性 | HASL / 沉金 / OSP 的选择与厚度 |

### 1. 设计

生产前，工程师需要在 EDA（电子设计自动化）软件里完成**原理图、PCB 设计方案与 BOM 物料清单**。这三份东西是后工序的全部输入：钻孔位置来自版图，位号与封装来自 BOM 与库，拼板方式来自板厂的工艺能力。

### 2. 钻孔

按设计方案在覆铜板的对应位置加工过孔与插件孔。这一步决定了板子上“哪里能穿孔、穿孔多大”，也决定了后面布线能用的资源——**孔是先于走线存在的物理约束**。

### 3. 显影（图形转移）

按设计好的线路图形，把一种**抗蚀（防腐）材料**精准地留在覆铜板上：要么丝印抗蚀油墨，要么贴干膜后曝光、再显影把未感光的部分洗掉。留下的抗蚀层，就是“未来铜线”的轮廓。

### 4. 蚀刻

把覆铜板浸入特定化学溶剂，**没有被抗蚀材料保护的铜被溶解去除**，于是设计里预期的导电铜路径被精确保留下来。蚀刻是“减成法”的核心——先有一整面铜，再减掉多余的。

<Callout type="idea" title="整条流程的本质：加法与减法">
钻孔 + 金属化是“加法”（往孔里加铜），图形转移 + 蚀刻是“减法”（把不要的铜去掉），阻焊与表面处理是“选择性覆盖”（该保护的保护、该露出的露出）。三种动作组合出全部结构，多复杂的板都是这三件事的重复与细化。
</Callout>

### 5. 阻焊涂层

铜线若长期裸露，会氧化、影响可靠性，甚至带来短路风险，所以需要在板上加一层绝缘涂层（阻焊层）。材料不同颜色也不同——墨绿、黑、蓝、红、白都有，**颜色之间不存在性能差异**。

### 6. 保留焊盘（阻焊开窗）

如果整块板被阻焊层完全覆盖，后续元件就没法通过焊盘与铜导线形成完整回路。因此阻焊层必须**在焊盘处开窗**、把铜露出来。开窗通常与阻焊图形同一次曝光显影完成，所以“开窗偏移”是这一工步最常见的缺陷。

### 7. 印制丝印

为了后续焊接、维护与辨识，在板上印一系列标识符号：元件位号、外框、方向、极性。丝印让“焊接过程更准确、更便捷”，也让几年后回来的维修人员看得懂这块板。

### 8. 可选工艺：表面处理

| 工艺 | 厚度量级 | 优点 | 注意 |
| --- | --- | --- | --- |
| 热风整平（HASL，喷锡） | 较厚、不平整 | 便宜、可焊性好、耐存放 | 细间距与 BGA 不友好 |
| 镀锡 | 薄 | 成本低，防氧化 | 多次回流后仍会氧化 |
| 沉金（ENIG） | 薄而平整 | 平整、适合细间距与金手指 | 成本高，注意“黑盘”风险 |
| 电镀硬金 | 较厚、耐磨 | 插拔寿命长 | 只用于触点区域 |
| OSP | 极薄 | 环保、平整、成本低 | 怕多次回流与长期存放 |

对长期暴露在空气中的焊盘，通常要做一次抗氧化二次处理，比如镀锡；而内存条、显卡、网卡这类**接口触点频繁插拔**的产品，会做镀金或沉金处理，以提高抗氧化能力、保证接触与信号传输的稳定性。

<Pitfall>表面处理不是“越贵越好”。沉金平整但脆、怕弯折；喷锡便宜但表面不平，细间距器件容易虚焊。选型要跟着封装与工艺窗口走。</Pitfall>

## 四、层数更多：四层板与叠层

一般 PCB 的层数按双数递增：2 层、4 层、6 层……**四层板可以理解为两块双面板夹着一层绝缘基材压合而成**（中间通过半固化片粘合）。这种结构增强了电路板的功能性与物理稳定性，适用于更复杂的电子设备。

<LayerStackup4 />

为什么四层板偏爱 **SIG / GND / PWR / SIG**？因为第二层的完整地平面既是参考面又是屏蔽层，第三层电源平面与它紧耦合，相当于给电源和地之间塞了一个天然的平板电容。**层数增加带来的最大好处，往往不是“多放几根线”，而是多了一个完整的参考平面。**

| 层数 | 典型叠层 | 适合什么 | 成本感受 |
| --- | --- | --- | --- |
| 2 层 | SIG / SIG | 低速、电源、极低成本 | 最低 |
| 4 层 | SIG / GND / PWR / SIG | 绝大多数中低速与入门高速产品 | 约 1.5–2 倍于双层 |
| 6 层 | SIG / GND / SIG / PWR / GND / SIG | DDR、千兆、射频 | 明显上升 |
| 8 层以上 | 多层信号 + 多组参考面 | 服务器、交换机、整机主板 | 大幅上升 |

<Callout type="warn" title="别用层数解决布线焦虑">
层数是最贵的解法。先把器件布局与信号流向理顺——很多“布不通”的板，问题在布局不在层数。
</Callout>

## 五、孔的分类：通孔、盲孔、埋孔

层数一多，孔就不再只有一种。按“这个孔要穿透到哪一层”来分：

| 类型 | 连接范围 | 制造时机 | 典型用途 | 成本 |
| --- | --- | --- | --- | --- |
| 通孔 Through Via | 从板的一侧穿透到另一侧（贯穿所有层） | 压合完成后一次钻通 | 插件元件、普通过孔 | 最低 |
| 盲孔 Blind Via | 从表层进入内层，但**不贯穿整板** | 需在对应压合阶段前钻出 | BGA 扇出、高密度布线 | 较高 |
| 埋孔 Buried Via | 只存在于内层之间，**不与表层相连** | 必须在压合前完成钻孔与电镀 | 内层高密度互连 | 最高 |

<ViaTypes />

<Callout type="info" title="术语对照">
埋孔（Buried Via）在部分资料里写作“盖孔”，指的都是同一种孔——**完全位于内层之间、不与表层相连**。看到“盖孔”按埋孔理解即可。
</Callout>

还有几个绕不开的孔：

- **微孔（microvia）**：孔径 ≤ 0.15 mm，用激光钻，是 HDI 板的核心工艺。
- **盘中孔（via in pad）**：孔直接打在焊盘里，需要填孔电镀再做表面处理，否则焊料会被吸走。
- **背钻（back drill）**：把通孔末端的残桩（stub）钻掉，改善高速信号的反射。
- **孔环（annular ring）**：焊盘外径与孔径之差的一半，太小会破环，太大占空间。
- **纵横比（aspect ratio）**：板厚 ÷ 孔径。比值越大，孔壁电镀越难均匀，通常控制在 8:1 以内。

<Pitfall>盲孔、埋孔不是“随便标一下就行”的。它们绑定叠层结构与压合次数——**设计早期定下来的叠层，决定了你后面能不能用盲埋孔**；中途改叠层，等于重做一版板子。</Pitfall>

## 六、板厂视角：设计端要交代的信息

| 设计端要给 | 板厂会问 | 说错的后果 |
| --- | --- | --- |
| 层数与叠层顺序 | 每层铜厚、介质厚度、是否阻抗控制 | 阻抗偏差、无法压合 |
| 线宽 / 间距下限 | 你们的工艺能力是否满足 | 做不到就加价，或直接报废 |
| 孔径与孔类型 | 最小孔径、是否有盲埋孔 | 盲埋孔需要额外压合次数 |
| 板厚与板材 | 板材型号、Tg、是否无铅 | 耐热不足，回流时板翘 |
| 表面处理 | HASL / 沉金 / OSP / 硬金 | 焊接不良或触点氧化 |
| 拼板与工艺边 | 拼板方式、Mark 点、V-Cut | 贴片机无法定位 |

## 七、要点速记

```text
双面板五要素：介质层、线路、通孔、阻焊层、丝印
介质层：玻纤布 + 环氧树脂（FR-4），负责绝缘与支撑
线路：铜箔经曝光 + 蚀刻形成，宽度管载流、间距管可制造性
通孔：孔壁镀铜，把上下层导通
阻焊层：防焊油墨，只在焊盘处开窗；颜色不影响性能
丝印：位号、外框、极性；不许压焊盘

工艺链：设计 → 开料 → 钻孔 → 沉铜电镀（PTH）→ 图形转移（曝光/显影）
      → 蚀刻 → 阻焊 → 丝印 → 表面处理 → 成型 → 电测

覆铜板 CCL = 铜箔 + 绝缘基材（+ 铜箔）；1 oz ≈ 35 µm
四层板 = 两块双面板 + 中间绝缘（半固化片压合）
常用四层叠层：SIG / GND / PWR / SIG

孔：通孔（穿全板）、盲孔（表层→内层）、埋孔（仅内层之间）
盲埋孔绑定叠层结构，设计早期就要定
```
