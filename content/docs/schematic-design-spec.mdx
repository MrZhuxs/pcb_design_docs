原理图是整块板子的**第一份契约**：电气上能不能工作，一大半在这一步就定下来了；
后面 PCB 阶段好不好做、软件好不好写，也都在这一步埋下伏笔。

这份规范解决三件事：**把概念对齐**、**把纪律写清楚**、**把需求卡在入口**。

<Callout type="info" title="怎么用这份规范">

- **画的中间**：随时对照 1.2 节的元件分类与串并联特性；
- **画完之后**：拿 1.3 节十条原则逐条自查 —— 这一遍能拦掉大部分返工。
</Callout>

## 1.1 电路的基本概念

> **电路**是各种元器件按照一定方式连接起来、实现某种功能的整体；从物理量的角度看，它是**提供电流流通的路径**。

### 1.1.1 按功能分类

电路按功能分成两类：

| 类别 | 做什么 | 例子 |
| --- | --- | --- |
| **第一类：能量转换** | 把一种形式的能量转换为电能 | 电力电路 —— 将机械能或热能转化为电能 |
| **第二类：信号处理** | 实现信号的传递、处理和控制 | 日常使用的电子产品 |

<Callout type="idea" title="分类的实际意义">
两类电路的设计目标不同：**第一类看效率与安全**（发热、绝缘、载流），
**第二类看信号完整性**（噪声、带宽、时序）。同一块板上往往两类都有 ——
电源部分是第一类，信号部分是第二类，**布局与检查清单要分开做**。
</Callout>

### 1.1.2 按处理的信号分类：模拟电路与数字电路

| 对比项 | 模拟电路 | 数字电路（逻辑电路） |
| --- | --- | --- |
| **处理对象** | 模拟信号：**连续变化**的电信号 | 数字信号：**仅有 0 与 1 两个状态** |
| **电路做什么** | 对模拟信号进行传输、变换、处理、放大、测量和显示 | 在数字时钟驱动下完成逻辑运算与控制 |
| **常见电路** | 放大电路、运算电路、振荡电路、调制器电路、电源电路 | 寄存器电路、乘法器电路 |
| **系统组成** | — | **控制部件 + 逻辑运算部件**：时钟驱动下，控制部件控制运算部件完成所要执行的动作 |
| **抗干扰能力** | — | **较强** |

<Callout type="warn" title="「数字抗干扰强」不是可以随便布线的理由">
数字电路抗干扰能力强，是因为它只需要区分两个状态、并且有足够的噪声裕量；
**裕量被吃掉了（地弹、串扰、参考平面分割）照样出错**，而且数字电路出错往往表现为偶发的、难复现的故障。
</Callout>

### 1.1.3 任何电路的三个基础部分

不管电路多复杂，拆到最后都由三个基础部分组成：

| 部分 | 作用 | 常见形态 |
| --- | --- | --- |
| **电源** | 提供电能（把其他形式的能量转换为电能） | 电池、直流电源、整流后的电源轨 |
| **负载** | 把电能转换为其他形式的能量，完成电路要做的功能 | 电机、LED、喇叭、芯片 |
| **中间环节** | 连接电源与负载，承担传输与控制 | 导线 / 走线、开关、连接器、控制与保护器件 |

<KeyBox title="1.1 要带走的一句话">
**电路 = 电源 + 负载 + 中间环节**。任何一个部分缺失，电路都不成立；
分析一个陌生电路时，先找出这三部分，再谈别的。
</KeyBox>

## 1.2 电路主要物理量

电路中最基础的物理量是**电流、电压和电功率**。
电路的分析主要是针对电路中电流、电压和电功率的分析；
有时也会涉及能量、磁通量、热力等物理量。

<KeyBox title="分析电路的固定三问">
1. **电流**走哪条路？有多大？（决定线宽、载流、回流）
2. 这一段路上的**电压**是多少？（决定绝缘、耐压、器件应力）
3. 这里消耗多少**电功率**？（决定封装、散热、降额）

三问答不上来，说明这个电路还没看懂。
</KeyBox>

### 1.2.1 三个基础物理量

| 物理量 | 专题 | 说明 |
| --- | --- | --- |
| **电流** | [《电流》篇](/docs/concepts/current) | 定义与单位、载流子、回路与回流路径、载流能力与压降、di/dt、测量与高频效应 |
| **电压** | [《电场、电势与电势能》篇](/docs/concepts/electric-field-and-potential) | 由电荷 → 电场 → 电势能 → 电势 → 电压一路推下来，落到板上的爬电距离与横向电场 |
| **电功率** | 待建专题 | 见文末「待补充」清单 |

### 1.2.2 电路元件

为了便于理解与分析电路元件，可以使用**电路模型**的方式来分析。

#### 电路模型：用理想元件近似实际电路

<Concept title="电路模型">
电路模型由**理想元件**组成，并用**统一规定的符号**表达。
它是由实际电路**抽象**而成，近似地反映实际电路的电气特性。
</Concept>

<WhyItMatters title="为什么可以先不管「次要因素」">
用理想电路元件建立的电路模型，使电路分析大大简化：
分析时**只考虑其中起主要作用的某些电磁现象或信号特性**，把次要因素忽略掉。

这就是**第一性原理**在电路分析里的用法 —— 先抓住主因把问题算清楚，
需要精度时再把次要因素一项一项补回来（寄生电感、ESR、结电容……），
而不是一开始就把所有因素堆在一起。
</WhyItMatters>

<Callout type="info" title="待补充：元件基础介绍">
【元件基础介绍】将独立成篇，见文末「待补充」清单。本节先建立**分类框架**与**分析方法**。
</Callout>

#### 按「有没有电源」分类：无源器件与有源器件

**无源器件（被动元器件）**：工作时，内部没有任何形式的电源 —— 也就是**元器件没有电源引脚**。

- **功能分布**
  - **电路类**：电阻器、电容器、二极管、电感、变压器、继电器……
  - **连接类**：接插件、插座、连接电缆
- **基本特点**
  - 自身消耗电能，或者把电能转化为不同形式的其他能量
  - 只需输入信号，**不需要外加电源**就能正常工作

**有源器件（主动元器件）**：工作时，其内部有电源存在 —— 也就是**需要电源供电**。

- **功能分布**
  - **分立器件**：双极型晶体管、场效应晶体管、晶闸管
  - **集成电路**
    - **模拟集成**：运算放大器、比较器、模拟开关、电源芯片
    - **数字集成**：逻辑门、可编程逻辑器件、数字接口芯片、微处理器
- **基本特点**
  - 自身消耗电能
  - 除了输入信号外，**还需要有外加电源**才能正常工作

| 对比项 | 无源器件（被动） | 有源器件（主动） |
| --- | --- | --- |
| **电源引脚** | 没有 | 有（必须供电） |
| **能否独自工作** | 只需输入信号即可 | 输入信号 + 外加电源，缺一不可 |
| **电能关系** | 自身消耗电能，或把电能转化为不同形式的其他能量 | 自身消耗电能 |
| **典型器件** | 电阻、电容、电感、二极管、变压器、继电器、接插件 | 三极管、场效应管、晶闸管、运算放大器、电源芯片、MCU |

<Callout type="idea" title="一个够用的判断口诀">
**看它有没有电源引脚。**
有电源引脚（VCC / VDD / VBAT）= 有源；没有 = 无源。
所以在原理图上，**只要看到某个器件连着电源轨，就要问：它的供电、去耦、上电时序安排了吗？**
</Callout>

### 1.2.3 节点、支路与回路

| 名称 | 定义 |
| --- | --- |
| **节点** | 两条及以上的网络连接点 |
| **支路** | 电路网络中的单个元件 |
| **干路** | 支路的集合，一条干路下存在多条支路 |
| **回路** | 一个连通的电路 |

#### 串联电路及其特性

> **串联**：将电路元件（如电阻、电容、电感等）**逐个顺次首尾相连**；
> 串联电路中**流过各元件的电流都相等**。

| 物理量 | 串联关系 |
| --- | --- |
| **电流** | I = I₁ = I₂ = I₃ = …… = Iₙ（处处相等） |
| **总电压** | U = U₁ + U₂ + U₃ + …… + Uₙ |
| **等效电阻** | R = R₁ + R₂ + R₃ + …… + Rₙ |
| **总功率** | P = P₁ + P₂ + P₃ + …… + Pₙ |
| **等效电容** | 1/C = 1/C₁ + 1/C₂ + 1/C₃ + …… + 1/Cₙ（**倒数相加**） |

除上面五条定量关系外，还有三条定性特征：

- 仅有一条通路，**各元件之间互相影响**（串联分压，一处变、处处变）
- 除**电流处处相等**外，其余各物理量之间均成正比 —— 串联电路也称为**分压电路**
- 电路中只要有某一处断开，整个电路就**断路（开路）**，所有串联的元件都无法正常工作

<Callout type="warn" title="串联电路最典型的失效方式">
串联链上任意一个元件虚焊、开路或损坏，**整条链一起不工作**。
所以设计上要有冗余判断：这条链上有哪个器件最可能失效？
它失效时，是"整条链停"（可发现的故障）还是"变成另一种工作状态"（不可发现的故障）？
</Callout>

#### 设计时需要注意

<Callout type="idea" title="并联使用时的两条经验">
- **避免电感并联**：并联电感产生的磁场会与其邻近电感的磁场发生耦合，
  导致电感之间互相影响 —— 尤其在**同向、靠近、同封装**时最明显。
- **不同容值的电容并联是常规做法**：容值大的负责滤波、储能，
  容值小的负责滤除高频干扰，两者覆盖不同频段，**不能互相替代**。
</Callout>

## 1.3 原理图设计规范基本原则

以下十条是原理图设计的通用纪律，逐条对照可以拦掉大部分返工。

1. **电路优化设计**
   - 选择使用**成熟**或者**集成度较高**的芯片进行电路设计
   - 满足性能的前提下，尽可能使电路**简化并减少元器件**，降低电路复杂度
   - **电路复杂度越高，该电路失效的可能性越大**

2. **各功能块布局要合理**：整份原理图需布局均衡，避免部分区域拥挤。
   【**PCB 设计同规则**】

3. **标识要清晰**：可调元件（如电位器）、切换开关、LED 指示灯、选配器件的标识要清晰，
   并在图上标注功能说明。【注释】

4. **关键信号要标注**：重要的控制线或信号线需标明**电流方向**和**信号幅值**，
   同时适当描述该信号的**软件控制方式** —— 包括：
   - 初始化控制模式
   - 正常工作控制模式
   - 待机时候控制模式

5. **参数标识准确、清晰**：特别需要注意**功率电阻、功率电感、高压电容**等器件。
   - 大功率器件需标明**功率值**
   - 耐高压的滤波电容需标明**耐压值**

6. **保证系统各模块资源不能冲突**：
   例如 SPI 总线同时挂几个外围设备时，每个设备要用**片选信号**进行控制，
   以保证**同一时刻只有一个设备有效**。

7. **未被使用的输入引脚需要确认是否要做处理**【阅读数据手册】，
   否则可能引起芯片内部振荡、发热等问题。

8. **为软件设计留出方便**：在不增加设计难度的情况下，尽量保证软件开发方便；
   或者以**较小的硬件设计代价**换取方便、可靠、高效的软件设计。

9. **软硬件要沟通**：进行原理图设计时，硬件设计人员需要与底层软件开发人员沟通，
   找到最佳控制方式。

10. **考虑 PCB 板散热问题**：在功耗和发热量大的芯片上增加散热片或风扇。

<KeyBox title="十条纪律的四个归属">
- **做减法**：1（复杂度就是失效概率）
- **让人看得懂**：2 / 3 / 4 / 5（布局均衡、标注清晰、参数齐全）
- **不许打架**：6 / 7（资源冲突、悬空引脚）
- **软硬件协同与散热**：8 / 9 / 10
</KeyBox>

## 1.4 确认需求

详细理解电路设计需求，从需求中整理出**电路功能模块**和**性能指标**等要求。

### 1.4.1 确认核心芯片

根据产品功能和性能需求制定硬件总体设计方案，对 CPU 进行选型。CPU 选择应满足：

- **性价比高**
- **可扩展性好**
- **生命周期长**
- **软件容易开发**

<Callout type="warn" title="选型要看的不是「最强」，而是「最省心」">
CPU 一旦定下来，**封装、电源树、时钟、接口、软件生态全部跟着定**，改型成本极高。
所以这四条要同时成立，任何一条明显短板都会在量产或迭代阶段变成问题。
</Callout>

### 1.4.2 参考成功案例

克隆其他商业产品的同功能电路，或者直接使用厂商自带的参考设计图。

<Callout type="idea" title="参考设计要用对">
参考设计给出的是**能工作的起点**，不是可以直接交付的终点：
原厂的参考设计通常按"演示板"的目标做（性能优先、成本和面积不敏感），
照抄时要按自己的需求重新确认 **BOM 成本、封装与面积、供货情况、以及被参考设计省略的保护电路**。
</Callout>

### 1.4.3 外围器件的选型

外围器件选型遵循七条原则：

1. **普遍性原则**
2. **高性价比方案**
3. **采购方便原则**
4. **持续发展原则**
5. **可替代性原则**
6. **向上兼容原则**
7. **资源节约原则**

<KeyBox title="七原则的共同指向">
这七条其实都在回答同一个问题：**这颗料，三年后我还买得到、还换得掉、还亏得起吗？**
所以在选型表里，除了"型号 / 参数 / 封装"，最好再记两列：**供货状态**与**备选料号**。
</KeyBox>
